# 書き方

画面の文言、docs、コードのコメント、テスト名で使う言葉と書き方の決まりです (手を入れる人向け)。
画面そのものの説明は [screens.md](screens.md) に、見た目の決まりは [design.md](design.md) にあります。

## 画面の言葉

画面と docs はこの呼び方にそろえます。一度使った呼び名は、同じ文書の中で言い換えません。

| 言葉       | 指すもの                                           | 例                     |
| ---------- | -------------------------------------------------- | ---------------------- |
| 局         | 番組を流す 1 つのサービス (番組表の 1 列)          | でんぱテレビ、BSでんぱ |
| チャンネル | 選局する物理チャンネル。1 つに複数の局が入っている | `T20`、`BS01:16400`    |
| 種別       | 放送の種類                                         | 地上波・BS・CS         |

ルールの「局」、ライブの局の一覧、検索の「これからの放送」(全局) は局です。設定の「チャンネル」にある
「受信できるチャンネル」「チャンネルスキャン」と、取得の進み具合に出る「8 / 8 チャンネル」はチャンネルです。
「サブチャンネル」だけは放送の呼び名のまま使います。中身は局です。

ボタンのラベルは、保存・追加・開始・実行・中断・削除・取消・予約・編集のように体言止めにします。
体言止めはラベルだけで、通知や説明の文は述語まで書きます。「閉じる」「戻す」のように名詞にすると不自然なものは動詞のままにします。
「番組表をいますぐ集める」「ルールを作る」のように、何をするかを文で言うボタンも動詞で終えます。

### 同じ操作・状態の文言

画面が違っても、同じ操作と同じ状態はこの文言にそろえます。テレビのアプリ (denpa-tv) に同じ文があるときは、あちらもそろえます。

| どんなとき                           | 文言                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| 削除の 2 回目 (押し間違いを防ぐ確認) | 「削除を確定」。保存した録画は「端末とサーバから削除」                                   |
| 止めるボタン (スキャン・エンコード)  | 「中断」「エンコード中断」                                                               |
| すぐ取得するボタン (番組表・ロゴ)    | 「番組表をいますぐ集める」「ロゴをいますぐ集める」。動いている間は「集めています…」      |
| 再生できる形式が 1 つも無い          | 「再生できる形式がありません」                                                           |
| 選んだ形式を再生できない             | 「再生できない形式です」。形式の選択肢では「(再生できません)」                           |
| スクランブルの処理                   | 「復号」。「スクランブル復号中」「スクランブルを復号しています」「復号できませんでした」 |
| 録画のためにライブの局が変わったとき | 「録画が始まったため、局を切り替えました」                                               |
| 条件から名前を作れないルール         | 「名前の無いルール」                                                                     |

番組表とロゴは、画面ではふだんの言葉の「集める」、docs とコメントでは処理の名前の「取得する」と書きます。

## 決まりを書く docs

決まりを並べる docs ([design.md](design.md) など) は、**大きな決まり → 章ごとの決まり → 細かい決まり → 例 → 例外** の順に書きます。

- 章の冒頭に、どの大きな決まりから来ているかを書く。章ごとの決まりは太字の 1 文にする
- 数値や CSS の名前は細かい決まりに付け、例はその決まりのすぐ下に短く置く
- 例外は理由が書けるものだけを、その決まりのすぐ下に書く。直す予定のずれは例外にせず、最後に分けて書く
- 前の章を読んでいない人も、その章だけで使えるように書く。章どうしをつなぐ文は書かない

## 文の書き方

**起きることと、することをそのまま書きます。** 画面の文言、docs、コメント、テスト名、PR の本文のどれも同じです。

- 通知や説明は要点だけの短い文にする。短くするときも、条件と理由は消さない。「この端末では」のような前置きや主語は、無くても通じるなら付けない (「再生が追いつかないため、変換した映像に切り替えました」)
- 1 つの文の中で動作する側が変わるときは、それぞれの主語を書く。人が操作した結果か、サーバが自動で動いた結果かを読み分けられるようにする
- 通知とエラーは、何をしたらどうなったかを組で書く。「注意してください」で終えない。してはいけない操作は、その操作と起きることを書く
- 機械やコードが主語の文に、人の動作や気持ちを表す動詞を使わない。「ログを吐く」は「ログを出力する」、「キューに投げる」は「キューに渡す」のように、何を受け取り、何を返し、何を呼ぶかで書く。関数やサーバを「知っている」「見張る」の主語にもしない。会話の俗語 (死ぬ・刺さる・筋がいい) も書かない。「テストが通る」「キャッシュが効く」「チューナーを譲る」のように定着した言い方は使ってよい
- 動詞の連用形を 1 語だけ名詞にしない。「結果の確かめ」「設定の直し」は「結果を確かめる」「設定を直す」と動詞で書くか、確認・修正のような定着した語を使う
- 英語 1 語に漢字 1 字を当てない。version を「版」、head を「頭」、title を「題」とせず、バージョン・先頭・冒頭・タイトルのように分野で使われている語にする
- 「〜することができる」「〜を行う」「〜の実施」は、動詞で短く書く (「削除することができます」→「削除できます」、「確認を行う」→「確認する」)
- 否定と対にした言い切りや、誰も言っていない誤解を先回りして打ち消す文を書かない。「これは単なる設定ではない。設計だ。」は、言いたいほうだけを書く。範囲を絞る否定と、間違えやすい事実の注意は残し、何を否定するかを具体的に書く
- 予告、まとめ、前置きの強調、定型の結びを書かない。「次の節では〜を説明します」「まとめると」「重要なのは」「ぜひ試してください」は消して、中身から書き始める
- 確かめたこと、推定、まだ確かめていないことを書き分け、文末を一律にぼかさない。済んだ変更 (〜した)、今の動作 (〜する)、これからの予定 (〜する予定) も書き分ける。「できる」「してよい」「しなければならない」「必ず」は意味が違うので、直すときに入れ替えない
- 間を置くためだけの読点、文の途中のダッシュ (— や ―)、文末のコロンを使わない (「録画は、開始しました」→「録画を開始しました」)。読点は条件・逆接・長い句の切れ目に打つ。値に付けるラベル (「残り: 3 分」) のコロンは使ってよい
- 括弧には短い補足だけを入れる。括弧の中が文や長い列挙になるなら、括弧の外に出して文を分ける
- 「の」を 3 つ以上続けない。「画面の設定の項目の名前」は「設定画面にある項目の名前」のように助詞や動詞を補う
- 半角の英数字と日本語の間には半角の空白を入れる (「1 つ」「BS の局」)。docs で多いほうの書き方です。コード (`T20`) と固有名 (BSでんぱ) の中はそのまま
- 区切りの「・」の前後には空白を入れない (「録画中・あと 21 分」)。項目の中に「・」がある列挙は、項目どうしを「、」で区切る (「番組名・概要、全局」)
- Amazon のリンク (「Amazon で見る (広告)」) は、載せると決めた機種に添えるだけにする。載せる機種と扱い (実機で確かめたか) はリンクのために変えず、「おすすめ」「ぜひ」「お得」のような売り込む言葉は書かない
- 太字は、章ごとの決まりの 1 文のように本当に目立たせたい所だけに使う。画面に出る文字は「」で囲んで示す。箇条書きの各項を「太字の語: 説明」の同じ形にそろえない

## 使わない言葉

**内輪で作った呼び名は使いません。** 画面の文言、docs、コードのコメント、テスト名のどれも、初めて読む人に通じる言葉で書きます。
画面の文言には、ボタン・aria-label・通知・エラー・サーバが返す理由がすべて入ります。
データ放送・字幕・スクランブル・サブチャンネルのような放送の正式な呼び名はそのまま使います。

下の表は置き換えの候補です。機械的に置き換えず、文の意味に合う語を選びます。合う語が決まらないときは、元の文が何を指しているかを確かめてから書き直します。

| 使わない言葉                                  | 代わりに                                                                                                |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 焼く・焼いたもの・焼き直す                    | エンコード (録画)・変換 (ライブ)・エンコード済みの動画・再エンコード                                    |
| 解く                                          | デコード・再生する・読み取る。スクランブルは復号                                                        |
| 解除 (スクランブルの)                         | 復号 (インタレ解除はそのまま)                                                                           |
| 無題 (ルール)                                 | 名前の無いルール                                                                                        |
| 生 TS                                         | 元の TS                                                                                                 |
| 絵                                            | 映像 (画面に出るもの)・フレーム・コマ (デコードした 1 枚)・画像 (静止画・字幕・ロゴ)・アイコン (ボタン) |
| 札                                            | ボタン・ラベル・ペアリングコード・チケット                                                              |
| 帯 (画面の下の操作の並び)                     | 操作バー                                                                                                |
| 環                                            | リングバッファ                                                                                          |
| 入/切・入り切り                               | オン/オフ                                                                                               |
| 掴む・借りる (チューナー)                     | 使う・取る                                                                                              |
| 跳ぶ                                          | 飛ぶ                                                                                                    |
| 乗る (チャンネルに局が)                       | 入っている                                                                                              |
| 拾う・取りに行く                              | 取得する (画面では「集める」)                                                                           |
| 口 (外から使う入口)                           | エンドポイント・API。画面ではボタン・リンク                                                             |
| 挿し口・番地 (USB)                            | ポート・アドレス                                                                                        |
| 読み口・書き口                                | 読み出し側・書き込み側                                                                                  |
| 道                                            | 経路・方式・パス                                                                                        |
| 入る道                                        | ログイン方法                                                                                            |
| 器                                            | コンテナ・入れ物・MediaSource。デコードするものはデコーダ                                               |
| 復号器・符号器・多重化器・合成器              | デコーダ・エンコーダ・マルチプレクサ・コンポジタ                                                        |
| 門                                            | 認証・チェック (意味に合わせる)                                                                         |
| 居る・居た・居場所                            | いる・ある・位置 (「居た場所から」→「再生していた位置から」)                                            |
| 本 (チューナー)                               | 台・チューナー (動画・ストリームの「1 本」はそのまま)                                                   |
| こま                                          | コマ・フレーム                                                                                          |
| 生で送る・生 (MPEG-2)                         | 変換せずに送る・放送のままの MPEG-2                                                                     |
| 題                                            | タイトル (副題はそのまま)                                                                               |
| 形 (データの)                                 | 形式                                                                                                    |
| 頼む・頼み直す                                | リクエストする・リクエストし直す・指定する                                                              |
| 板                                            | パネル                                                                                                  |
| 軌道 (音声・字幕の)                           | トラック                                                                                                |
| 読み手 (チューナーのストリームを読んでいる側) | 利用者・接続・使っている処理。データを読む関数ならパーサ・読み取り関数                                  |
| 蹴る・蹴られる (録画がチューナーを取る)       | 取り上げる・切断する・譲らせる                                                                          |
| 相乗り                                        | 共有 (同じストリームを共有する)。サブチャンネルなら「本チャンネルと同じ番組を流している」               |
| 見回り                                        | 定期チェック                                                                                            |
| アプリの鍵・鍵 (Bearer)                       | アクセストークン                                                                                        |
| 知らせ (名詞)                                 | 通知 (「知らせる」はそのまま)                                                                           |
| 叩く (API を)                                 | 呼ぶ                                                                                                    |
| 流れ (ストリームの意味)                       | ストリーム                                                                                              |
| 強さ (チューナーの取り合い)                   | 使わない (表の下を参照)                                                                                 |
| 版 (ソフトウェア・形式の)                     | バージョン (「新しい版」→「新しいバージョン」、「開発版」→「開発ビルド」、「第 1 版」→「バージョン 1」) |

チューナーの取り合いでは、画面に数字を出しません。何に使っているか (録画・ライブ視聴・番組表の取得) と、足りないときにどの用途を先にするかの順を出します。
この順はチューナーの節の「詳しく」に並べます。「優先度」は、ルールに付ける 0〜9 の値にだけ使います。
