# 書き方

画面の文言・docs・コードのコメント・テスト名の言葉の決まりです (手を入れる人向け)。
画面そのものの説明は [screens.md](screens.md)、見た目の決まりは [design.md](design.md)。

## 画面の言葉

画面と docs はこの呼び方にそろえます。

| 言葉           | 指すもの                                          | 例                     |
| -------------- | ------------------------------------------------- | ---------------------- |
| **局**         | 番組を流す1つのサービス (番組表の1列)             | でんぱテレビ、BSでんぱ |
| **チャンネル** | 選局する物理チャンネル。1つに複数の局が入っている | `T20`、`BS01_0`        |
| **種別**       | 放送の種類                                        | 地上波・BS・CS         |

ルールの「局」、ライブの局の一覧、検索の「これからの放送」(全局) は局です。設定の「チャンネル」の
「受信できるチャンネル」「チャンネルスキャン」、取得の進み具合の「8 / 8 チャンネル」はチャンネルです。
「サブチャンネル」だけは放送の呼び名のまま使います (中身は局)。

ボタンは**体言止め** (保存・追加・開始・実行・中断・削除・取消・予約・編集)。名詞にすると不自然なもの
(閉じる・戻す) と、何をするかを文で言うもの (番組表をいますぐ集める・ロゴをいますぐ集める・ルールを作る) は動詞のままです。
一覧の行に並べる操作は、字が小さくても押せる範囲を高さ 40px 以上にします (観る画面の操作列と同じ。`app.css` の `.row-actions`)。

### 同じことは同じ文言で

画面が違っても、同じ操作・同じ状態はこの文言にそろえます。テレビのアプリ (denpa-tv) に同じ文があるときは、あちらもそろえます。

| どんなとき                          | 文言                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| 削除の2回目 (押し間違いを防ぐ確認)  | **削除を確定**。保存した録画は **端末とサーバから削除**                                |
| 止めるボタン (スキャン・エンコード) | **中断**・**エンコード中断**                                                           |
| すぐ取得するボタン (番組表・ロゴ)   | **番組表をいますぐ集める**・**ロゴをいますぐ集める**。動いている間は **集めています…** |
| 再生できる形式が1つも無い           | **再生できる形式がありません**                                                         |
| 選んだ形式を再生できない            | **再生できない形式です**。形式の選択肢では **(再生できません)**                        |
| スクランブルを解く処理              | **復号** (スクランブル復号中・スクランブルを復号しています・復号できませんでした)      |
| ライブが録画に譲った                | **録画のため局を切り替えました**                                                       |
| 条件から名前を作れないルール        | **名前の無いルール**                                                                   |

## 決まりを書く docs

決まりを並べる docs ([design.md](design.md) など) は、**大きな決まり → 章ごとの決まり → 細かい決まり → 例 → 例外** の順に書きます。

- 章の頭に、どの大きな決まりから来ているかを書き、章ごとの決まりは太字の 1 文にする
- 数値や CSS の名前は細かい決まりに付け、例はその決まりのすぐ下に短く置く
- 例外は理由が書けるものだけを、その決まりのすぐ下に書く。直す予定のずれは例外にせず、最後に分けて書く

## 使わない言葉

**身内の言葉は使いません。** 画面の文言 (ボタン・aria-label・通知・エラー・サーバが返す理由) だけでなく、
docs・コードのコメント・テスト名も、初めて読む人に通じる言葉で書きます。放送の正式な呼び名
(データ放送・字幕・スクランブル・サブチャンネル) はそのままです。
通知や説明は**要点だけの短い一文**にします。「この端末では」のような前置きや主語は、無くても通じるなら付けません
(「再生が追いつかないため、変換した映像に切り替えました」)。
