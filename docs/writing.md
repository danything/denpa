# 書き方

画面の文言・docs・コードのコメント・テスト名の言葉の決まりです (手を入れる人向け)。
画面そのものの説明は [screens.md](screens.md)。

## 画面の言葉

画面と docs はこの呼び方にそろえます。

| 言葉 | 指すもの | 例 |
| --- | --- | --- |
| **局** | 番組を流す1つのサービス (番組表の1列) | でんぱテレビ、BSでんぱ |
| **チャンネル** | 選局する物理チャンネル。1つに複数の局が入っている | `T20`、`BS01_0` |
| **種別** | 放送の種類 | 地上波・BS・CS |

ルールの「局」、ライブの局の一覧、番組表の検索 (全局) は局です。チューナー画面の
「受信できるチャンネル」「チャンネルスキャン」、取得の進み具合の「8 / 8 チャンネル」はチャンネルです。
「サブチャンネル」だけは放送の呼び名のまま使います (中身は局)。

ボタンは**体言止め** (保存・追加・開始・実行・中断・削除・取消・予約・編集)。名詞にすると不自然なもの
(閉じる・戻す) と、何をするかを文で言うもの (番組表をいますぐ集める・ルールを作る) は動詞のままです。
一覧の行に並べる操作は、字が小さくても押せる範囲を高さ 40px 以上にします (観る画面の操作列と同じ。`app.css` の `.row-actions`)。

## 使わない言葉

**身内の言葉は使いません。** 画面の文言 (ボタン・aria-label・通知・エラー・サーバが返す理由) だけでなく、
docs・コードのコメント・テスト名も、初めて読む人に通じる言葉で書きます。放送の正式な呼び名
(データ放送・字幕・スクランブル・サブチャンネル) はそのままです。
通知や説明は**要点だけの短い一文**にします。「この端末では」のような前置きや主語は、無くても通じるなら付けません
(「再生が追いつかないため、変換した映像に切り替えました」)。

| 使わない言葉 | 代わりに |
| --- | --- |
| 焼く・焼いたもの・焼き直す | エンコード (録画)・変換 (ライブ)・エンコード済みの動画・再エンコード |
| 解く | デコード・再生する・読み取る。スクランブルは復号 |
| 生TS | 元のTS |
| 絵 | 映像 (画面に出るもの)・フレーム・コマ (デコードした1枚)・画像 (静止画・字幕・ロゴ)・アイコン (ボタン) |
| 札 | ボタン・ラベル・ペアリングコード・チケット |
| 帯 (画面の下の操作の並び) | 操作バー |
| 環 | リングバッファ |
| 入/切・入り切り | オン/オフ |
| 掴む・借りる (チューナー) | 使う・取る |
| 跳ぶ | 飛ぶ |
| 乗る (チャンネルに局が) | 入っている |
| 拾う・取りに行く | 取得する |
| 口 (外から使う入口) | エンドポイント・API。画面ではボタン・リンク |
| 挿し口・番地 (USB) | ポート・アドレス |
| 読み口・書き口 | 読み出し側・書き込み側 |
| 道 | 経路・方式・パス |
| 入る道 | ログイン方法 |
| 器 | コンテナ・入れ物・MediaSource。デコードするものはデコーダ |
| 復号器・符号器・多重化器・合成器 | デコーダ・エンコーダ・マルチプレクサ・コンポジタ |
| 門 | 認証・チェック (意味に合わせる) |
| 居る・居た・居場所 | いる・ある・位置 (「居た場所から」→「再生していた位置から」) |
| 本 (チューナー) | 台・チューナー (動画・ストリームの「1本」はそのまま) |
| こま | コマ・フレーム |
| 生で送る・生 (MPEG-2) | 変換せずに送る・放送のままの MPEG-2 |
| 題 | タイトル (副題はそのまま) |
| 形 (データの) | 形式 |
| 頼む・頼み直す | リクエストする・リクエストし直す・指定する |
| 板 | パネル |
| 軌道 (音声・字幕の) | トラック |
| 読み手 (チューナーのストリームを読んでいる側) | 利用者・接続・使っている処理。データを読む関数ならパーサ・読み取り関数 |
| 蹴る・蹴られる (録画がチューナーを取る) | 取り上げる・切断する・譲らせる |
| 相乗り | 共有 (同じストリームを共有する)。サブチャンネルなら「本チャンネルと同じ番組を流している」 |
| 見回り | 定期チェック |
| アプリの鍵・鍵 (Bearer) | アクセストークン |
| 知らせ (名詞) | 通知 (「知らせる」はそのまま) |
| 叩く (API を) | 呼ぶ |
| 流れ (ストリームの意味) | ストリーム |
| 強さ (チューナーの取り合い) | 使わない。画面には数字を出さず、何に使っているか (録画・ライブ視聴・番組表の取得) と譲り合う順 (「詳しく」) を出す。「優先度」は画面ではルールの数 (0〜9) だけに使う |
