# PT3 など (Linux DVB)

Linux の DVB ドライバで動くチューナーです。**Linux だけで使えます** (Mac と Windows には DVB がありません)。
地上波か衛星かは、デバイスに聞いて自動で見分けます。
denpa が使える内蔵のカードリーダーは無いので、USB のカードリーダーを別に挿します ([tuners.md](tuners.md#カードリーダー))。

チューナーの一覧は [tuners.md](tuners.md)、エージェントの中でどう扱っているかは [agent.md](agent.md#デバイスを開いたままチャンネルを変える)。

## 機材とドライバ

**実機で確かめているのは PT3 だけです。** ほかの機材は、カーネルのドライバと denpa の選局の手順を照らし合わせて「動くはず」と見ているもので、
実機では確かめていません。使ってみたら、動いた・動かなかったを教えてください ([下記](#動いたか教えてください))。

### 実機で確かめた機材

| 機材                  | 種別           | 使うドライバ            | メモ                                   |
| --------------------- | -------------- | ----------------------- | -------------------------------------- |
| PT3 (Earthsoft、PCIe) | 地上波2・衛星2 | mainline の `earth_pt3` | 1枚で `/dev/dvb` にアダプタが4つ出ます |

### 実機で確かめていない機材

| ---------------------------------------------------------------- | -------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PT1 / PT2 (Earthsoft、PCI)                                       | 地上波2・衛星2 | mainline の `earth_pt1`                                                          | PT3 と同じ復調 IC (`tc90522`) です                                                                                                                                                                                         |
| PX-BCUD (PLEX、USB)                                              | 衛星1          | mainline の `em28xx` (Linux 4.7 以降)                                            | ドライバに LNB の電源の切り替えが無く、denpa からは電源を指示できません。LNB を選んでいても電源の指示は飛ばして選局し、そのことを記録に1回だけ残します                                                                     |
| PX-S1UD (PLEX、USB)                                              | 地上波1        | mainline の Siano `smsusb` + `smsdvb`                                            | ホストに firmware `isdbt_rio.inp` が要ります。smsusb を blacklist すれば、ホストに何も入れない siano-userland でも使えます ([tuner-px-s1ud.md](tuner-px-s1ud.md))                                                          |
| Friio (白、USB)                                                  | 地上波1        | mainline の `dvb_usb_gl861`                                                      | 内蔵のカードリーダーはカーネルが扱わないので、USB のカードリーダーを別に挿します                                                                                                                                           |
| 南米の地デジ (ISDB-Tb) の機材                                    | 地上波         | mainline の `dvb_usb_dib0700`、または `mb86a20s` を使うドライバ (`cx231xx` など) | Pixelview SBTVD・EvolutePC TVWay+・Kworld UB430-AF・C3 Tech Digital Duo・MyGica X8502 / X8507 など。電波の形は日本の地デジと同じです。地上波だけで、dib0700 の機材はホストに firmware `dvb-usb-dib0700-1.20.fw` が要ります |
| DiBcom の DiB8096 のリファレンス基板 (STK8096GP・NIM8096MD など) | 地上波         | mainline の `dvb_usb_dib0700`                                                    | CECH-ZD1 J と同じ DiB8096 を載せた基板です。ホストに firmware `dvb-usb-dib0700-1.20.fw` が要ります                                                                                                                         |

次の機材は、ドライバはあっても denpa では動かない見込みなので載せていません。

- **Siano のうち PX-S1UD (Rio) と Pele 以外** — 地上波の選局がワンセグになります
- **Leadership ISDBT** — ワンセグのモジュールです
- **Digital Devices の CXD2838 / CXD2854** — mainline のチューナーのドライバが地デジの選局を受け付けません

## 入れ方

1. **ホストでドライバを読み込みます。** どれも mainline のカーネルに入っているドライバです。
   `/dev/dvb/adapter0` などが出ていれば準備はできています。
   Talos Linux なら、ドライバは system extension `siderolabs/dvb-pt3` で入ります (PT3 だけ。[install-talos.md](install-talos.md))
2. **denpa を入れます** ([install.md](install.md#1行で入れる))。compose.prod.yml・`denpa-aio`・Helm は、
   どれも `/dev/dvb` をディレクトリごと渡してあります。compose.prod.yml と `denpa-aio` の手順は
   DVB のデバイス (212) を開く許可も付けてあるので、挿し直しても再起動は要りません
3. **設定の「受信」の「チューナー」で確かめ、「チャンネル」でスキャンします。** 見つかったチューナーと種別が並びます

## 設定

- **設定の `device` は `/dev/dvb/adapterN/frontendM`** です。挿さっていれば自動で組み立てるので、普段は書きません
- **衛星のアンテナに電源を送るなら、設定の「受信」の「チューナー」で行の「⋯」を開き、LNB で 15V を選びます。**
  DVB には 18V (`SEC_VOLTAGE_18`) を指示します (11V は 13V。recisdb と同じ対応)。
  ドライバに電源の切り替えが無い機材 (PX-BCUD など) では電源を指示せずに選局し、記録に「この機材は LNB の電源を出せません」と1回だけ残します
- **一度選局したチューナーは、エージェントを止めるまで開いたままにします。** チャンネルは開いたまま切り替えます

## うまくいかないとき

- 設定の「受信」の「チューナー」に出てこない — ホストに `/dev/dvb/adapter*` があるか、コンテナに `/dev/dvb` を渡しているかを見ます
- 選局はできるのに映らない (スクランブルのまま) — カードリーダーを見ます ([tuners.md](tuners.md#直らないとき))。
  `denpa-agent --tune ... --decode` で、選局と復号を1回だけ試せます (同じ節)

## 動いたか教えてください

実機で確かめていない機材を使ったら、動いたか動かなかったかを [Issue](https://github.com/danything/denpa/issues) で教えてください。
設定の「その他」→「ログ」の「Issue にする」を使うと、サーバとエージェントのログと環境を、カードの番号や IP アドレスを伏せて
Issue のフォームに入れられます ([screens.md](screens.md#バグの報告))。機材の名前と、地上波・衛星のどちらで試したかを書き添えてもらえると助かります。
動いた報告をもらった機材は「実機で確かめた機材」に移します。
