# 画面まわり (ホーム画面・ライブ)

**録画はブラウザでそのまま観ます** (`/watch/<id>`。[library.md](library.md#観るのはブラウザで))。
テレビのアプリ・落として手元のプレイヤーで観る道は
[library.md](library.md#手元のプレイヤーで観る) に。

## 操作まわりは3画面で共通

**同じものを2つ書かない。** ライブ (`/live`)・追っかけ (`/chase/<id>`)・観る画面
(`/watch/<id>`) はどれも絵の上にボタンを重ねる画面です。別々に書いていた頃は
同じ「再生」でも形も敷き方も違ったので、`src/lib/components/player/` に寄せました。

| | 何を持つか |
| --- | --- |
| `icons.ts` | アイコン（Lucide。[下](#アイコンは-lucide-を組むときに埋め込みます)）と、絵の上に置くボタンの色 |
| `Icon.svelte` | アイコン1つ（大きさと `aria-hidden`） |
| `ControlButton.svelte` | 重ねるボタン。押されている間の見え方もここ |
| `ControlBar.svelte` | 絵に重ねる列。下端の帯（黒いぼかしつき）と、右端の縦の列（中身は画面ごと: 観る画面は閉じる・d・切り抜き・削除、ライブは録画・d・切り抜き、追っかけは閉じる・切り抜き）。低い枠では右の列を右上の一行に寝かせる |
| `controls.svelte.ts` | 出すか消すかの決め方。マウスは動かせば、指は押せば出て、どちらも 2.5 秒で消える。止めていても消える（一時停止は絵の中の文字を見るためで、帯が残っては意味が無い）。残すのはキーボードで触っている間とメニューを開いている間だけ |
| `awake.svelte.ts` | 観ている間、画面を暗くさせない（Wake Lock）。入り切りは無く、止めている間も掛けたまま（一時停止して絵を見ている間に消えていた） |
| `frames.ts` | 映した1枚ごとに呼ぶ。字幕の貼り直しと CM の跨ぎがこれに乗る（`timeupdate` は 250ms ごとにしか来ない） |
| `paint.ts` | 字幕の重ね方。映像の画素そのままの大きさで敷いて、放送の座標に置く |
| `PlayerStage.svelte` | 舞台の枠。ポインタ・キー・全画面の配線と、黒地で 16:9 の枠。枠の大きさを測って詰め方を決める（幅 448px 未満 = `data-compact`: スマホの縦。高さ 360px 未満 = `data-low`） |
| `Extras.svelte` / `MoreButton.svelte` | 狭い枠で「毎回は使わないもの」（音声・送り・CM 飛ばし・焼き方・速さ・バックグラウンド再生・小窓）を「ほか」(⋯) に畳む。広い枠では何もしない。並べ替えは CSS の `order` だけ（DOM は1か所） |
| `MediaStack.svelte` | 映像と重ねもの（前の絵・字幕 canvas）の束。BML が触るので class でなく style |
| `PlayerVeil.svelte` | 読み込み中・失敗・待ちの幕。前の絵を貼っている間は塗り潰さない |
| `OverlayMenu.svelte` | 絵の上のドロップダウンの共通部分（選択肢の並びと閉じ方） |
| `CodecMenu.svelte` / `AudioMenu.svelte` / `SpeedMenu.svelte` | 焼き方・音声・速さのメニュー。トリガーごと共通 |
| `EdgeButton.svelte` | 「今」へ張り付くボタン（ライブの「ライブ」・追っかけの「最新」） |
| `InfoBlock.svelte` | 帯の中の読みもの（二段）。上が「時間帯 ・ 局 ・ 番組名」、下が画面ごとの状態（位置・遅延など） |
| `FactsAside.svelte` | 右の「番組の中身」の列の枠（観る画面・追っかけ）。中身が長ければここだけ巻き取られ、押すものは外に貼り付く |
| `StageNote.svelte` | 絵の上に浮かせる短い知らせ（角丸の黒い札。テーマ色を絵に乗せない） |
| `keys.ts` | キーの割り当て（空白/k 再生・← → 10秒・c 字幕・s 切り抜き・f 全画面・&lt; &gt; 速さ・m 消音）。観る画面と追っかけで同じ。修飾キー付きと IME 変換中は取らない（Ctrl+C を字幕に取られてコピーできなかった） |
| `center-tap.ts` | 真ん中あたりを素早く2回で再生/一時停止（指の端末だけ。1回目は操作列の出し入れ）。使うのはライブだけで、追っかけは観る画面と同じ `ts/watch.ts` の `tap`（マウス1回で再生/一時停止、端2回で 10秒） |
| `pip.svelte.ts` | 小窓 (ピクチャーインピクチャー)。帯の全画面の左に置き、狭い枠では「ほか」に畳む。iPhone・iPad のホーム画面から開いたもの (PWA) は Safari が小窓を許さないので、ボタンごと出さない。ページから小窓を開かせる口の無いブラウザでも出さない。生 (MPEG-2) で見ているときは worker が描いた絵を別の `<video>` に流して出す (Chrome は worker が直に書き込む。canvas の画面への更新から取ると、窓が隠れたとき絵が止まる。Safari は canvas から取る。Firefox は生の絵を取れないので、生の間はボタンを出さない)。小窓で押した止める・再開はライブと追っかけの帯にも写す。**字幕も小窓に出す** (Chrome・Edge。`compose.ts` がコマごとに字幕の canvas を重ねた流れを作り、別の `<video>` を小窓にする。焼いたものは押した時点で字幕を出しているときだけ・小窓に出している間だけ重ねる。Safari・Firefox は字幕無し)。操作列は小窓に付いていかない。denpa の別の画面 (番組表など) へ移ると、再生ごと止まって小窓も閉じる |
| `fullscreen.svelte.ts` / `fullscreen.ts` | 全画面の出入り（帯のボタンと `f`）。端末の口で入り方を決める（[下](#全画面は端末の口で入り方を変えます)） |
| `background.svelte.ts` / `background.ts` | バックグラウンド再生の入り切り（帯のヘッドホン。狭い枠では「ほか」に畳む）。既定は切で、裏に回したら止める（[下](#裏に回したら止めます)） |
| `shot.svelte.ts` / `snapshot.ts` | いまの1コマを字幕ごと切り抜いて PNG に（`番組名_YYYYMMDD-HHMMSS.png`）。指の端末は共有シート（写真へ保存・そのまま送る）、PC は落としてクリップボードにも置く。生（MPEG-2）で見ているときは worker に1枚貰う（`raw/engine.ts` の `grab`） |
| `DataBroadcast.svelte` / `Remote.svelte` | データ放送の器と、指で押せるリモコン |

決め方を2箇所に持っていた頃は、観る画面の帯が押したときにしか出ず、隠れた帯の上を
押すと下の絵が受け取って再生が止まっていました。**消え方は指もマウスも同じ 2.5 秒です**
(指だけ押すまで留めていた時期は、消すたびに絵を押すはめになった)。

### 切れたら繋ぎ直します

**サーバを入れ替えると（デプロイ）、観ている最中に配信が切れます。** 器ごと作り直すので
数十秒戻りませんが、戻ることは分かっているので、すぐには諦めません。

| | 切れたあと |
| --- | --- |
| ライブ | WebSocket を張り直して同じ局を選び直す（1秒→2秒→…10秒で頭打ち）。回数の上限は無い |
| 観る画面 | 同じファイルを読み直して切れた瞬間の位置へ戻す（15秒おきの続きではなく）。待ちは同じく倍々で10秒が頭打ち。続けて8回（約1分）で諦めて落とす口を出す |

どちらも待っている間は「繋ぎ直しています」と出します。**読めない形式や壊れたファイルは
拾い直しません。** 何度やっても同じなので、すぐ落とす口を出します。

### 裏に回したら止めます

**バックグラウンド再生は既定で切です。** ホームへ戻る・別のアプリやタブへ移ると止め、戻ってきたら
続きから再開します（ライブで放送の今に張り付いていたなら、放送の今へ戻る）。入り切りは帯の
ヘッドホンで、端末ごとに覚えます（速さ・CM 飛ばしと同じ `localStorage`）。

| | 切（既定） | 入 |
| --- | --- | --- |
| 裏に回したとき | 止める | 止めない |
| OS・ブラウザが自分で小窓にする（全画面からホームへ戻った iPhone など） | させない（`disablePictureInPicture`） | 任せる |
| 生（MPEG-2）の音の Audio Session（Safari） | `auto` のまま | `playback`（裏でも鳴らす） |

**押して開いた小窓（`pip.svelte.ts`）は切でも使えます。** 出している間は裏に回しても止めず、
生の音も `playback` にします。閉じた時点でまだ裏なら、そこで止めます。

### 全画面は端末の口で入り方を変えます

**入れるのは枠ごとです**（映像だけでなく字幕・データ放送・操作列も一緒に大きくする）。
ボタンの絵（広げる/縮める）はどの入り方でも今の状態を映します。

| 端末 | 入り方 | 出口 |
| --- | --- | --- |
| PC・Android・iPadOS 16.4 以降 | `requestFullscreen()` | ボタン・`f`・Esc・端末の戻る（UA が持つ） |
| それより前の iPadOS | `webkitRequestFullscreen()` | 同上 |
| iPhone の Safari | **枠を画面いっぱいに広げる**（`position: fixed`。後ろのページは止めて黒く） | ボタン・`f`・Esc・**戻る**（広げたときに履歴を1段積む。もう一度戻ると前の画面へ） |

iPhone は要素の全画面を持たず、あるのは `<video>` だけの `webkitEnterFullscreen` です。
あれは映像だけを OS の再生画面に渡すので字幕・データ放送・操作列が置いていかれ、使いません。
広げたときの向きは固定できません（iPhone の Safari は `screen.orientation.lock` を持たない）。
横に持てば横いっぱいになります。別の画面へ移ると畳みます。

### アイコンは Lucide を、組むときに埋め込みます

**アイコンは [Lucide](https://lucide.dev/icons) に揃えています**（線の太さ 2・角丸。
`currentColor` で文字の色に従う）。読み込みは **Iconify の形の束 (`@iconify-json/*`) を
[unplugin-icons](https://github.com/unplugin/unplugin-icons) で組むときに Svelte の部品へ
変える**やり方です（`import Play from '~icons/lucide/play'`。`vite.config.ts`）。

- **実行中に取りに行かない。** denpa は家の LAN だけ・オフラインでも開くものなので、
  Iconify の API から形を取る `@iconify/svelte` の既定の使い方は採りません。束に入るのは
  使ったアイコンの `<svg>` だけで、SSR でもそのまま出ます（後から絵が差し込まれてずれることもない）。
  service worker が持つのも普通の JS の束です
- **`@iconify/svelte` を形を渡して使う道も比べました。** 実行時の部品と、形のデータ
  (`@iconify-json/*` は1つの束で全部入り、`@iconify-icons/*` は古い形式) を両方
  束に入れることになり、unplugin-icons より重く、依存も増えます
- **`lucide-svelte` を直に使わないのは、ほかの集まりも同じ書き方で足せるから。**
  局やサービスのロゴが要るときは `@iconify-json/simple-icons` を足して `~icons/simple-icons/*`
- 足した依存はどちらも開発時だけ（`devDependencies`）。束に入るのは Lucide の形 (ISC) だけです
  ([licenses.md](licenses.md))
- **Lucide に無い形は `src/lib/icons/*.svg` に置きます**（`~icons/denpa/*`）。いまはデータ放送の
  「d」だけ（リモコンと同じ字。線の太さと角は Lucide に揃えた）

ロゴ・PWA のアイコン (`static/`)・局ロゴ・データ放送の画面は「アイコン」ではないので対象外です。

## LAN でも https で開く

**持っているドメインの名前を LAN 内のアドレスに向ければ、公開しないまま本物の証明書が
使えます**（DNS-01 なので外から繋がる必要が無い。`.arpa` のような内側だけの名前は ACME で
取れない）。この家では chart の `httpRoute.hostnames` に足した https://dp.l.doany.io で、
名前は家の中でだけ引け、そこから来た人には何も聞きません
（[auth.md](auth.md#ネットワークの中なら何も聞かない)）。テレビのアプリや手元のプレイヤーが録画を取りに来るのも
同じ口です。ホーム画面に置けるのも全画面にできるのも https のページだけなので、PWA にも要ります。

## ホーム画面に置く

denpa は PWA なので、ブラウザの「ホーム画面に追加」でアプリのように開けます
(アドレス欄もタブも出ません)。

**名前が2つあると、置いたアイコンが見分けられません** (どちらも「denpa」で絵も同じ)。
そこで、どの名前で来たかで表示名を変えられます (`PWA_NAMES`)。

```sh
PWA_NAMES='dp.doany.io=denpa,dp.l.doany.io=denpa 宅内'
```

書き方は `ホスト名=表示名` のカンマ区切りで、載っていない名前で来たら `denpa`。
`name` と `short_name` に同じものが入ります（アイコンの下に出るのは `short_name` で、
端末によっては十数文字で切られる）。

> **入れ直すまで名前は変わりません。** ブラウザは追加した時点のマニフェストを覚えます
> （Chrome は読み直すこともあるが当てにできない）。変えたらアイコンを入れ直してください。

**同じ端末に2つ置けます。** 名前が違えば別のサイトで、マニフェストの `id` も名前ごとに
分けてある（`/?host=<名前>`）ので、片方がもう片方の入れ直しと見なされません。

マニフェストは `static/` ではなく `/manifest.webmanifest` の口で組み立てます
（`src/lib/server/manifest.ts`）。**認証は掛けていません。** ブラウザが資格情報を付けずに
取りに来るためで（[auth.md](auth.md)）、出しているのは名前・色・アイコンの場所だけです。

### 開き直したら読み直します

**ホーム画面から開いたアプリは、閉じても捨てられません。** 端末が凍らせて残し、次に
開くとそのまま見せるので、前に閉じたときの一覧がリロードするまで出ていました。
見えるようになったところで1回読み直します（`+layout.svelte`）。知らせ（SSE）は
凍っている間に切られて自分では戻らず、繋ぎ直しても間に起きたことは流れてこない
（溜めていない）ので、それだけでは足りません。繋ぎも同じところで張り直します（`live-updates.svelte.ts`）。

## ライブ視聴

**放送中のものもブラウザで観られます**（`/live`。作りは [stream.md](stream.md)）。
録画の観る画面とは作りが別物です。ライブは WebSocket + MSE で放送に追いつき続け、
録画はファイルを `<video>` に渡すだけです。
