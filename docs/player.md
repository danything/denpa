# 画面まわり (ホーム画面・ライブ)

**録画はブラウザでそのまま観ます** (`/watch/<id>`。[library.md](library.md#観るのはブラウザで))。
テレビの VLC へ飛ばす・落として手元のプレイヤーで観る道は
[library.md](library.md#手元のプレイヤーで観る) に。

## 操作まわりは3画面で共通

**同じものを2つ書かない。** ライブ (`/live`)・追っかけ (`/chase/<id>`)・観る画面
(`/watch/<id>`) はどれも「絵の上にボタンを重ねる」画面で、別々に書いていた頃は
同じ「再生」でも形も敷き方も違っていました。いまは `src/lib/components/player/`
に寄せてあります。

| | 何を持つか |
| --- | --- |
| `icons.ts` | アイコンの形と、絵の上に置くボタンの色 |
| `Icon.svelte` | アイコン1つ |
| `ControlButton.svelte` | 重ねるボタン。押されている間の見え方もここ |
| `ControlBar.svelte` | 絵に重ねる列。**下端の帯**（黒いぼかしつき）と、**右端の縦の列**（中身は画面ごと: 観る画面は閉じる・d・切り抜き・削除、ライブは録画・d・切り抜き、追っかけは閉じる・切り抜き） |
| `controls.svelte.ts` | **出すか消すかの決め方。** マウスは動かせば、指は押せば出て、**どちらも 2.5 秒で消える。止めていても消える**（一時停止は絵の中の文字を見るためで、帯が残っては意味が無い）。残すのは**キーボードで触っている間とメニューを開いている間だけ** |
| `awake.svelte.ts` | **観ている間、画面を暗くさせない**（Wake Lock）。入り切りは無く、**止めている間も掛けたまま**（一時停止して絵を見ている間に消えていた） |
| `frames.ts` | **映した1枚ごとに呼ぶ。** 字幕の貼り直しと CM の跨ぎがこれに乗る（`timeupdate` は 250ms ごとにしか来ない） |
| `paint.ts` | **字幕の重ね方。** 映像の画素そのままの大きさで敷いて、放送の座標に置く |
| `PlayerStage.svelte` | 舞台の枠。ポインタ・キー・全画面の配線と `bg-black aspect-video` の枠 |
| `MediaStack.svelte` | 映像と重ねもの（前の絵・字幕 canvas）の束。BML が触るので class でなく style |
| `PlayerVeil.svelte` | 読み込み中・失敗・待ちの幕。前の絵を貼っている間は塗り潰さない |
| `OverlayMenu.svelte` | 絵の上のドロップダウンの共通部分（選択肢の並びと閉じ方） |
| `CodecMenu.svelte` / `AudioMenu.svelte` / `SpeedMenu.svelte` | 焼き方・音声・速さのメニュー。トリガーごと共通 |
| `EdgeButton.svelte` | 「今」へ張り付くボタン（ライブの「ライブ」・追っかけの「最新」） |
| `InfoBlock.svelte` | 帯の中の読みもの（二段）。上が「時間帯 ・ 局 ・ 番組名」、下が画面ごとの状態（位置・遅延など） |
| `FactsAside.svelte` | 右の「番組の中身」の列の枠（観る画面・追っかけ）。中身が長ければここだけ巻き取られ、押すものは外に貼り付く |
| `StageNote.svelte` | 絵の上に浮かせる短い知らせ（`bg-black/60` の札。テーマ色を絵に乗せない） |
| `keys.ts` | **キーの割り当て**（空白/k 再生・← → 10秒・c 字幕・s 切り抜き・f 全画面・&lt; &gt; 速さ・m 消音）。**観る画面と追っかけで同じ**。修飾キー付きと IME 変換中は取らない（Ctrl+C を字幕に取られてコピーできなかった） |
| `center-tap.ts` | **真ん中あたりを素早く2回で再生/一時停止**（指の端末だけ。1回目は操作列の出し入れ）。**使うのはライブだけ** — 追っかけは観る画面と同じ `ts/watch.ts` の `tap`（マウス1回で再生/一時停止、端2回で 10秒） |
| `shot.svelte.ts` / `snapshot.ts` | いまの1コマを字幕ごと切り抜いてクリップボードへ |
| `DataBroadcast.svelte` / `Remote.svelte` | データ放送の器と、指で押せるリモコン |

決め方を2箇所に持っていた頃は、観る画面の帯が**押したときにしか出ず**、隠れた帯の上を
押すと下の絵が受け取って再生が止まっていました。**消え方は指もマウスも同じ 2.5 秒です** —
指だけ押すまで留めていた時期は、実機で**消したいたびに絵を押すことに**なりました。

### 切れたら繋ぎ直します

**サーバを入れ替えると（デプロイ）、観ている最中に配信が切れます。** 器ごと作り直すので
数十秒帰ってきませんが、帰ってくることは分かっているので、すぐには諦めません。

| | 切れたあと |
| --- | --- |
| ライブ | WebSocket を張り直して同じ局を選び直す（1秒→2秒→…10秒で頭打ち）。**上限は置いていません** |
| 観る画面 | 同じファイルを読み直して**切れた瞬間の位置**へ戻す（15秒おきの続きではなく）。待ちは同じく倍々で10秒が頭打ちで、**続けて8回（約1分）で諦めて**落とす口を出す |

どちらも待っている間は「繋ぎ直しています」と出します。**読めない形式や壊れたファイルは
拾い直しません** — 何度やっても同じなので、すぐ落とす口を出します。

## LAN でも https で開く

**持っているドメインの名前を LAN 内のアドレスに向ければ**、公開しないまま本物の証明書が
使えます（DNS-01 なので外から繋がる必要が無い。`.arpa` のような内側だけの名前は ACME で
取れない）。この家では chart の `httpRoute.hostnames` に足した **https://dp.l.doany.io** で、
名前は家の中でだけ引け、そこから来た人には何も聞きません
（[auth.md](auth.md#ネットワークの中なら何も聞かない)）。テレビの VLC が録画を取りに来るのも
同じ口です。**https は PWA のためでもあります** — ホーム画面に置けるのも、全画面にできるのも
https のページだけです。

## ホーム画面に置く

denpa は PWA なので、ブラウザの「ホーム画面に追加」で**アプリのように**開けます
(アドレス欄もタブも出ません)。

**名前が2つあると、置いたアイコンが見分けられません。** どちらも「denpa」で、
絵も同じだからです。そこで**どの名前で来たかによって表示名を変えられる**ように
してあります (`PWA_NAMES`)。

```sh
PWA_NAMES='dp.doany.io=denpa,dp.l.doany.io=denpa 宅内'
```

書き方は `ホスト名=表示名` のカンマ区切りで、載っていない名前で来たら `denpa`。
`name` と `short_name` に同じものが入ります（アイコンの下に出るのは `short_name` で、
端末によっては十数文字で切られる）。

> **入れ直すまで名前は変わりません。** ブラウザは追加した時点のマニフェストを覚えます
> （Chrome は読み直すこともあるが当てにできない）。変えたらアイコンを入れ直してください。

**同じ端末に2つ置けます。** 名前が違えば別のサイトで、マニフェストの `id` も名前ごとに
分けてある（`/?host=<名前>`）ので、片方がもう片方の入れ直しと見なされません。

マニフェストは `static/` ではなく `/manifest.webmanifest` の口で組み立てます
（`src/lib/server/manifest.ts`）。**認証は掛けていません** — ブラウザが資格情報を付けずに
取りに来るためで（[auth.md](auth.md)）、出しているのは名前・色・アイコンの場所だけです。

### 開き直したら読み直します

**ホーム画面から開いたアプリは、閉じても捨てられません。** 端末が凍らせて残し、次に
開くとそのまま見せるので、**前に閉じたときの一覧が**リロードするまで出ていました。
見えるようになったところで1回読み直します（`+layout.svelte`）。知らせ（SSE）だけでは
足りません — 凍っている間に切られて**自分では戻らず**、繋ぎ直しても間に起きたことは
流れてこない（溜めていない）ためです。繋ぎも同じところで張り直します（`live-updates.svelte.ts`）。

## ライブ視聴

**放送中のものもブラウザで観られます**（`/live`。作りは [stream.md](stream.md)）。
録画の観る画面とは**作りが別物**です — ライブは WebSocket + MSE で放送に追いつき続ける
必要があり、録画はファイルを `<video>` に渡すだけで済みます。
