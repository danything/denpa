# これから

やると決めたもの。**入ったものはそれぞれの文書へ移してあります** —

## ライブ視聴の残り

**映像・音声・字幕 (第1〜2段階) は入りました** — 画面も焼き方も遅延の詰め方も
[stream.md](stream.md) に移してあります。残っているのはこれだけ。

- **データ放送** (第3段階) — **解いてサイドチャネルに流すところまで入りました**
  (`ts/bml.ts` / `server/databroadcast.ts`)。映像は denpa が持ったまま、**解くのも
  自前**です (運び方は衛星のロゴと同じ DSM-CC で、既に持っていました)。
  **描く側も入りました** — web-bml の `BMLBrowser` を借りて、d ボタンで映像の上に
  重ねます (`components/player/DataBroadcast.svelte`)。押されるまで 700KB を
  取りに行きません。残っているのは**実機での詰め** (`programInfo` を自前の
  番組表から作る、双方向のプロキシ、指で押せるリモコン)
  ([stream.md](stream.md#56-データ放送の統合))

**低遅延の追い込み (WebRTC/WHEP) はやめました。** 縮むのは受け側の貯め (0.2秒) だけで、
開いてから映るまではむしろ伸び、「止めた所から見られる」「5分戻れる」を捨てることに
なります ([stream.md](stream.md#webrtc--whep-による低遅延化--不採用))。
本当に縮めたいなら、運び方ではなく**焼くのをやめる**ほうが桁で効きます。
