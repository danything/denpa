# EPGStation からの引き継ぎ

**録画・ルール・手動予約を、EPGStation から denpa へ移します。** 設定画面から
実行するもので、**何度走らせても二重にはなりません** (録画とルールは取り込み済みを飛ばす。
手動予約は予約し直す — 下記)。

| 探しもの | 見る場所 |
| --- | --- |
| 全体像 | [architecture.md](architecture.md) |
| 環境変数の一覧 | [app.md](app.md) |
| 保存先の形 | [library.md](library.md) |

## 先に用意するもの

**2つ見えるようにします。** どちらかが欠けていると実行できません。

| 何を | どうやって | 変数 |
| --- | --- | --- |
| **EPGStation の録画置き場** | その PVC (かディレクトリ) を denpa の Pod に**マウント**する | `EPGSTATION_RECORDED_DIR` (既定 `/epgstation-recorded`) |
| **EPGStation v2 の MariaDB** (`recorded` / `rule` / `reserve`。v1 は見ない) | denpa から届くところに置く。読むだけ | `EPGSTATION_DB_*` (既定は [app.md](app.md#環境変数)) |

**録画置き場が見えていないと、設定画面はボタンごと出しません** (`migrate.available`)。「引き継ぎ元 ○○ が
見えません」と出ているなら、まだマウントできていません。`charts/` にも `compose.prod.yml` にも
**雛形は入れていません** — 1回きりで、済んだら外すものなので、手元の EPGStation に合わせて足してください。

## やり方

**先に番組表を集めておきます。** 空のまま走らせると手動予約だけ入りません (下記)。

1. `/settings` の **「EPGStation からの引き継ぎ」**
2. **「実際に取り込む」を外したまま実行する** — 何が入るかを出すだけで、ファイルも
   データベースも触りません。件数と、飛ばされるものの理由がログに出ます
3. 中身を見て問題なければ、**「実際に取り込む」を入れて**もう一度実行する

進み具合はそのカードの中に push で出ます。**数百GBのコピーになるので、開始だけ受けて裏で進みます。**

**既定はコピーです。** 元をそのまま残すので、中身を確かめてから EPGStation 側を
消せます。**空き容量が足りないときだけ「コピーではなく移動する」**を入れてください。

## 何が入って、何が入らないか

**順番はルール → 手動予約 → 録画**です。録画のコピーがいちばん長いので、先に
ルールと予約を済ませておけば、**途中で止めても予約は動き出します。**

### ルール (`rule`)

キーワード・除外キーワード・**キーワードを当てる範囲** (番組名・説明・詳細説明)・種別 (GR/BS/CS/SKY)・
チャンネル・ジャンル・有効かを移します。当てる範囲まで引き継ぐのは、denpa の既定に寄せると説明まで
見ていたルールが**黙って当たらなくなる**ためです。名前はキーワードをそのまま使い、空なら
`EPGStation #<id>` になります。

- **時刻指定のルールは入りません** (denpa に当たるものが無い)
- **キーワード・チャンネル・ジャンル・種別がどれも空のルール**は飛ばします (全番組に当たるため)。
  種別だけのルールは入り、その種別の全番組に当たるので、下見のログで確かめてください

> **焼き方は移しません。** コーデックもCMの扱いも denpa では全体設定です ([library.md](library.md))。
> 引き継いだあとに `/settings` で決め直してください。

### 手動予約 (`reserve`)

**ルールから作られたものは移しません** (`ruleId IS NULL` のものだけ。ルールを移せば denpa が作り直す)。
除外印 (`isSkip`) の付いたものと、**もう終わっている番組**も飛ばします。

**denpa の番組表にその番組が無いと入りません。** 番組表を集める前に走らせると「番組表に無いので
取り込めません」が並ぶので、埋まってからもう一度実行してください。**走らせ直すと、手動予約は
取り込み済みでも予約し直します** — 二重にはなりませんが (番組ID の UNIQUE)、denpa 側で取り消した
ものは予約に戻ります。

### 録画 (`recorded`)

生TSとエンコード済みの両方があれば**エンコード済みを取り**、置き場は「denpa 自身が録ったとき」と同じに
揃えます (EPGStation の `video_file.type` で分ける)。

| 向こうの型 | 置く先 | |
| --- | --- | --- |
| `encoded` | **保存先** (`LIBRARY_DIR`) | 完成品として扱う。サムネイルも作る |
| それ以外 (生TS) | **作業領域** (`RECORDED_DIR`) | denpa 側で**焼き直せる**状態になる |

生TSを保存先に置くと denpa からは「エンコード済み」に見え、**録り直せず、プレイヤーにも巨大な MPEG-2 が
並びます。** サムネイルを作るのも保存先に置いたものだけです (作業領域は画面に出ない)。

- **元のパスは3通りで探します** (EPGStation は相対でも絶対でも持つ)。見つからないものは `missing` として
  ログに残し、**行だけ作ることはしません**
- **取り込み済みは飛ばします。** EPGStation の ID の符号を反転して `program_id` に入れてあるので、denpa の
  番組IDと衝突せず、止めて再開しても二重に入りません (ルールは `source` の `epgstation:<id>` で見分けます)

## 済んだら

**マウントと `EPGSTATION_*` を外します。** 引き継ぎが済めば要らないもので、
残しておくと設定画面にボタンが出たままになります。

元の PVC を消すのは、**denpa 側で中身を確かめてから**にしてください
(コピーで取り込んだ場合、消すまでは EPGStation もそのまま動きます)。
