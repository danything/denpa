# 画面

偽の放送 (作り物の局・番組・映像) で撮った画像です。撮り直し方は [development.md](development.md#readme-の画像)。

立て方は [install.md](install.md)。

## 録画

予約と録画を**1本の一覧**に並べます。上がこれからの予約 (遠い先が上、「いま」に近いほど下)、
赤い「いま」の線と録画中の行、その下に録れたもの (新しい順) です。日付ごとに見出しが付き、
一覧の頭に貼り付きます。開いたときは、観終えていない録画があればいちばん古いものを映し
(溜まったぶんを古い順に片付けられるように)、無ければ「いま」の線を映します。

録画の行はサムネイル付きで、押せばその場で観る画面へ
(録っている最中のものは「いま」の線の下にいて、その行の「追っかけ」で追っかけ再生へ。[library.md](library.md#観るのはブラウザで))。
予約の行を押すと番組の詳細が開きます。行は指で押せる高さ (48px) で、枠や線は無く、触れると薄く塗られます。

![録画](images/dashboard.webp)

広い画面 (1000px 以上) では右にサイドバーが出ます。上から次の順です。

- **絞り込み**: すべて・予約・録画中・未視聴・失敗。どれにも件数が付きます (未視聴は観終えていない録画。途中まで観たものも入ります。失敗は録画やエンコードの失敗と録り逃し)
- **表示の切り替え**: まとめて表示・完了した予約も表示・削除済みも表示・ファイルと照合
- **今日**: 次の録画 (あと何分か)・録画中・未視聴・空き (あと何時間録れるかの目安)
- **選んだ番組**: 指を乗せた行 (キーボードなら焦点のある行、指で触る端末では最後に開いた行) の中身。何も選んでいなければ「いま」にいちばん近いもの。再生・追っかけ・予約取消をその場で押せます

狭い画面では、一覧の頭のボタン (いまの絞り込みと件数が出ます) から、絞り込みと表示の切り替えを下から出る一枚で選びます。
番組名で探すのは、ホームではなく全体の検索です。

録画の行を押すと、そのまま観る画面へ:

![録画の行から観る画面へ](images/home-watch-anim.webp)

予約や録画が溜まってきたら、「まとめて表示」で**番組ごと**にまとめられます
(端末ごとに覚えます)。まとめる単位は、エンコード済みの動画を置くシリーズのフォルダと同じです。
予約にも録画にも効き、同じ番組でも予約は「いま」の線の上、録画は線の下と、側ごとに別の見出しになります
(番組の位置は、予約は次の回、録画は最新の回で決まります)。見出しを押すと放送順に開きます。
1本しか無い番組はまとめずにふつうの行のまま出ます。開いた番組の頭と、録画の詳細には
「ルールを作る」があり、シリーズ名を入れたルールの下書きを持ってルール画面へ行きます
(既にその番組を録っているルールがあれば、作らずにそちらを案内します)。

「詳細」で番組の中身と操作。「端末に保存」
(オフライン視聴)、「ルールを作る」、「その他…」に視聴済みにする (未視聴に戻す)・再エンコード・CM検出のやり直し。
録画をファイルとして持ち出すダウンロードはありません ([library.md](library.md#観るのはブラウザで))。
コマ数 (30/60) や字幕の有無もここに出ます。

![録画の詳細と操作](images/detail-anim.webp)

## 番組表

局ごとの縦の列。マスの左の線がジャンルの色で、予約済み・録画中は線の色が変わります。
いまの線が引かれ、押せば詳細が開いてそこから予約・取消。番組を言葉で探すのは[検索](#検索)です。

コピー禁止の番組は録りません ([data.md](data.md#コピー禁止の番組は録らない))。マスと詳細に小さく
「コピー禁止」と出て、予約のボタンは出ません。ルールが当たった予約は「録画しない」になり、
予約の一覧に「コピー禁止の番組なので録画しません」と出ます。放送が終わっても録り逃しにはせず、「完了分も表示」で
理由ごと見られます。ライブの録画ボタンも同じ一文で断ります。
観るのはそのままできます。

![番組表から詳細を開く](images/guide-anim.webp)

BS/CS はロゴをカルーセルから取得して出します ([logo.ts](../src/lib/server/logo.ts))。

![BS の番組表](images/guide-bs.webp)

## ライブ

放送中のものをそのままブラウザで。映像・音声・字幕・データ放送が入っていて、
局は右の一覧から切り替え。止めれば追っかけ再生になります ([stream.md](stream.md))。

![ライブ視聴](images/live-anim.webp)

## 録画を観る

エンコード済みの録画をブラウザで (エンコード前・エンコードに失敗したものは、サーバがその場で変換して流します)。字幕は放送どおりの位置に重ね、CMは自動で飛ばします (1コマも見せません)。
シークバーの CM のところは琥珀色で分けます (denpa-tv と同じ色)。
右は番組の中身、下の操作バーに再生・字幕・速さ、右の列に閉じる・d・切り抜き・削除。

操作バーはライブ・追っかけと同じ作りで、ボタンはいつも1行に並べます。スマホの縦のように幅が足りないときは、
よく使うもの (観る画面は再生・チャプター送り・時刻・⚙・全画面、ライブと追っかけは再生・ライブ/最新・⚙・全画面) だけを残し、
音・字幕・速さ・小窓は「⚙」(再生の設定) の頭に行として入ります (「⋯」のボタンはありません)。
CMスキップ・アンビエントモード・バックグラウンド再生・互換モード・字幕の言語・音声・コーデックは、幅にかかわらず「⚙」(再生の設定) に入っています。
時刻も「0:31 / 1:00:00」だけの短い形にします。

![観る画面](images/watch.webp)

## ルール

キーワード・ジャンル・局で自動予約。左にルールの一覧、真ん中に書く欄、右に「この条件で録れる番組」が並びます
(1280px より狭いと、録れる番組は書く欄の下に出ます)。録れる番組は書く欄を打つそばから変わります。
一覧の先頭の「＋ 新しいルール」で書く欄が空のまま開きます。言葉からルールを作るときやルールを探すときは[検索](#検索)から
(「ルールを作る」で書く欄にその言葉が入ります)。
一覧の行を押すとそのルールを直せます。有効/無効は行のスイッチで開かずに切り替えられます (一覧を隠すスマホの幅では、書く欄の下にも削除と並んでいます)。
スマホの幅では一覧が先に出て、ルールか新しいルールの行を押すと書く欄に切り替わります (「← ルール一覧」か戻るで一覧へ)。

「同じ回は最初の放送だけ録る」(新しく作るルールは入った状態で始まります) を入れておくと、
`[新]` のようなゆるい条件で拾っても、局を替えた再放送や同時放送は録りません。
同じ時刻に流れているなら字幕のあるもの、次に BS/CS を選びます。録らないものも一覧に
「録らない」として、どの放送で録るのかと一緒に出ます。

![ルール](images/rules.webp)

## 検索

番組表・録画・予約・ルールを1つの言葉でまとめて探します。広い画面ではヘッダーの真ん中の欄から
(どこからでも `/` か Ctrl+K (Mac は ⌘+K) で入れます。入力欄で字を打っている間は効きません)、
スマホの幅では下のタブの「検索」から (上の帯に同じ欄が出て、欄に入った状態で開きます)。
結果の画面にも同じ欄がそのままあり、探した言葉が入ったまま直して探し直せます。
結果の URL (`/search?q=…`) はそのまま人に渡せます。

結果は「これからの放送」「録画」「予約」「ルール」に分かれ、それぞれ件数と先頭の5件を出します (残りは「もっと見る」)。
読み方はどれも同じで、空白で区切った語をすべて含むものが当たります (全角/半角・大文字/小文字は区別しません)。

- **これからの放送** … 番組名と概要に当たる、まだ終わっていない番組。行から予約・取消と「ルールを作る」(その番組のシリーズ名で下書き)。
  行を押すと番組の詳細。見出しの横の「「…」でルールを作る」は、探した言葉をそのままキーワードにした書く欄を開きます
- **録画** … 番組名・シリーズ・副題・局名に当たる録画。押せば観る画面へ (録っている最中のものは追っかけ再生へ)。削除もここから
- **予約** … これから録るものといま録っているもの。押せば詳細、取消もここから
- **ルール** … 名前とキーワードに当たるルール。押せばそのルールを直せます

言葉なしで開くと、その端末で最近探した言葉が並びます (サーバには送りません)。

## 設定

左にグループとその節の一覧、右にグループの画面が並びます (ルールと同じ形)。グループごとに1つの画面 (`/settings/<グループ>`) で、節は上から積んであります。
一覧の節を押すとその節まで滑らかに巻き (`/settings/<グループ>#<節>`)、巻いていくと見えている節が一覧で塗られます。戻る・進むもそのまま使えます。
スマホの幅では一覧 (グループだけ) が先に出て、押すとその画面に切り替わります。画面の上に「← 設定」と節の名前の行があり、巻いても残ります。広い画面で「設定」を開くと、先頭の「一般」が開きます。

| グループ | 節 | 中身 |
| --- | --- | --- |
| 一般 (`general`) | この端末 (`browser`) | 画面の高さを見る (端末ごと)。テーマはヘッダー (スマホは下の「その他」)、互換モードは再生画面の ⚙ で切り替えるので、ここには置きません |
| | ログイン (`login`) | ログアウト・ほかの端末からもログアウト (ログインして使っているときだけ。素通しではその旨の1行) |
| | バージョン (`version`) | 動いている版。新しい版のリンクはヘッダー (スマホは「その他」) に出ます |
| 録画 (`recording`) | エンコード (`encoding`) | コーデックとそのエンコーダ (ソフトウェア・GPU)・同時に変換する本数・元のTSを残すか・コマ数 |
| | CM (`cm`) | CMの扱い |
| | 自動予約 (`reserve`) | 無料放送だけにするか |
| 受信 (`reception`) | チューナー (`tuners`) | チューナーの空きとカードリーダー、チューナーの設定。**うまくいかないときはまずここ** |
| | チャンネル (`channels`) | 受信できるチャンネルと番組表の集まり具合。チャンネルスキャン (種別を選んで「スキャン」。回っている間は「中断」) と「番組表をいますぐ集める」は見出しの行にあります |
| | ロゴ (`logos`) | 局ごとに、番組表に出す局ロゴとCM検出のために覚えたロゴ。「ロゴをいますぐ集める」と「覚え直す」 |
| | データ放送 (`broadcast`) | 郵便番号と都道府県・双方向 |
| 連携 (`integrations`) | 通知 (`notifications`) | 通知先 (Webhook) |
| | テレビのアプリ (`tv`) | ペアリングしたテレビ |
| | EPGStation からの引き継ぎ (`migrate`) | |

説明は要点1行で、続きは「詳しく」に畳んであります。前の節ごとの画面 (`/settings/tuners` など) と前のチューナーの画面 (`/tuners`) は、グループの画面のその節へ送ります。

### 局が無いとき

どの種別にも局が1つも無いと、録画・番組表・ライブの上に「チャンネルがありません。チャンネルスキャンをしてください」と1行出し、
[スキャンへ] で設定の「チャンネル」を開きます。閉じるボタンは無く、スキャンして局が入れば消えます。
地上波だけ無いとき (衛星だけの家) は出しません。番組表では、選んでいる種別に局が無ければ「地上波のチャンネルがありません。…」とボタンを表の場所の真ん中に出します (このときは上の1行を出しません)。
