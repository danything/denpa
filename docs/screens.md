# 画面

偽の放送 (作り物の局・番組・映像) で撮った画像です。撮り直し方は [development.md](development.md#readme-の画像)。

立て方は [install.md](install.md)。

## 画面の言葉

画面と docs はこの呼び方にそろえます。

| 言葉 | 指すもの | 例 |
| --- | --- | --- |
| **局** | 番組を流す1つのサービス (番組表の1列) | でんぱテレビ、BSでんぱ |
| **チャンネル** | 選局する物理チャンネル。1つに複数の局が入っている | `T20`、`BS01_0` |
| **種別** | 放送の種類 | 地上波・BS・CS |

ルールの「局」、ライブの局の一覧、番組表の検索 (全局) は局です。チューナー画面の
「受信できるチャンネル」「チャンネルスキャン」、取得の進み具合の「8 / 8 チャンネル」はチャンネルです。
「サブチャンネル」だけは放送の呼び名のまま使います (中身は局)。

ボタンは**体言止め** (保存・追加・開始・実行・中断・削除・取消・予約・編集)。名詞にすると不自然なもの
(閉じる・戻す) と、何をするかを文で言うもの (番組表をいますぐ集める・ルールを作る) は動詞のままです。
一覧の行に並べる操作は、字が小さくても押す的を高さ 40px 以上にします (観る画面の操作列と同じ。`app.css` の `.row-actions`)。

**身内の言葉は使いません。** 画面の文言 (ボタン・aria-label・通知・エラー・サーバが返す理由) だけでなく、
docs・コードのコメント・テスト名も、初めて読む人に通じる言葉で書きます。放送の正式な呼び名
(データ放送・字幕・スクランブル・サブチャンネル) はそのままです。
通知や説明は**要点だけの短い一文**にします。「この端末では」のような前置きや主語は、無くても通じるなら付けません
(「再生が追いつかないため、変換した映像に切り替えました」)。

## 予約と録画

左が予約、右が録画。録画の行はサムネイル付きで、押せばその場で観る画面へ
(録っている最中のものは予約の側にいて、その行の「追っかけ」で追っかけ再生へ。[library.md](library.md#観るのはブラウザで))。

![予約と録画](images/dashboard.webp)

録画の行を押すと、そのまま観る画面へ:

![録画の行から観る画面へ](images/home-watch-anim.webp)

録画が溜まってきたら、録画の見出しの「まとめて表示」で**番組ごと**にまとめられます
(端末ごとに覚えます。オンの間はボタンが主の色で塗られます)。まとめる単位は、エンコード済みの動画を置くシリーズのフォルダと同じです。
番組は最新の回が新しい順に並び、見出しを押すと第1話から放送順に開きます。
1本しか無い番組はまとめずにふつうの行のまま出ます。絞り込みはそのまま効き、
絞っている間は当たった番組を開いて出します。まとめているときは一覧の一番上
(最近録れた番組) から開きます。開いた番組の頭と、録画の詳細には
「ルールを作る」があり、シリーズ名を入れたルールの下書きを持ってルール画面へ行きます
(既にその番組を録っているルールがあれば、作らずにそちらを案内します)。

「詳細」で番組の中身と操作。「端末に保存」
(オフライン視聴)、「ルールを作る」、「その他…」に視聴済みにする (未視聴に戻す)・再エンコード・CM検出のやり直し。
録画をファイルとして持ち出すダウンロードはありません ([Discussion #760](https://github.com/danything/denpa/discussions/760))。
コマ数 (30/60) や字幕の有無もここに出ます。

![録画の詳細と操作](images/detail-anim.webp)

## 番組表

局ごとの縦の列。マスの左の線がジャンルの色で、予約済み・録画中は線の色が変わります。
いまの線が引かれ、押せば詳細が開いてそこから予約・取消。上の欄で全局の
番組名から検索できます。

コピー禁止の番組は録りません ([data.md](data.md#コピー禁止の番組は録らない))。マスと詳細に小さく
「コピー禁止」と出て、予約のボタンは出ません。ルールが当たった予約は「録画しない」になり、
予約の一覧に「コピー禁止の番組なので録画しません」と出ます。放送が終わっても録り逃しにはせず、「完了分も表示」で
理由ごと見られます。ライブの録画ボタンも同じ一文で断ります。
観るのはそのままできます。

![番組表から詳細を開く](images/guide-anim.webp)

BS/CS はロゴをカルーセルから取得して出します ([logo.ts](../src/lib/server/logo.ts))。

![BS の番組表](images/guide-bs.webp)

## ライブ

放送中のものをそのままブラウザで。映像・音声・字幕・データ放送が入っていて、
局は右の一覧から切り替え。止めれば追っかけ再生になります ([stream.md](stream.md))。

![ライブ視聴](images/live-anim.webp)

## 録画を観る

エンコード済みの録画をブラウザで (エンコード前・エンコードに失敗したものは、サーバがその場で変換して流します)。字幕は放送どおりの位置に重ね、CMは自動で飛ばします (1コマも見せません)。
シークバーの CM のところは琥珀色に塗ります (denpa-tv と同じ色)。
右は番組の中身、下の操作バーに再生・字幕・速さ、右の列に閉じる・d・切り抜き・削除。

操作バーはライブ・追っかけと同じ作りで、ボタンはいつも1行に並べます。スマホの縦のように幅が足りないときは、
よく使うもの (観る画面は再生・チャプター送り・時刻・全画面、ライブと追っかけは再生・ライブ/最新・全画面) だけを残し、
音・字幕・音声・エンコード方式・CM 飛ばし・速さ・バックグラウンド再生・小窓は「⋯」(ほかの操作) にまとめます。
時刻も「0:31 / 1:00:00」だけの短い形にします。

![観る画面](images/watch.webp)

## ルール

キーワード・ジャンル・局で自動予約。書きながら右に「いま何が引っかかるか」が出ます。

「同じ回は最初の放送だけ録る」(新しく作るルールは入った状態で始まります) を入れておくと、
`[新]` のようなゆるい条件で拾っても、局を替えた再放送や同時放送は録りません。
同じ時刻に流れているなら字幕のあるもの、次に BS/CS を選びます。録らないものも一覧に
「録らない」として、どの放送で録るのかと一緒に出ます。

![ルール](images/rules.webp)

## 設定

使う頻度の順に、録画のしかた (コーデック・元のTSを残すか・CMの扱い・コマ数・無料放送だけか)、テレビのアプリ (繋いだ端末)、通知先、データ放送 (郵便番号と都道府県・双方向)、GPU (同時に変換する本数も)、EPGStation からの引き継ぎ、画面の高さを見る、互換モードで再生 (動画が止まってしまう端末向け。端末ごと)。説明は要点1行で、
続きは「詳しく」に畳んであります。上から下へ巻いています。
