# 2.0 で変わったこと

1.x から上げた人向けに、場所が変わったもの・無くなった設定・新しくできたことをまとめます。
上げ方はいつもと同じです ([install.md](install.md#1行で入れる))。DB は起動したときに自動で移ります。

## 場所が変わったもの

| 1.x                                                           | 2.0                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「予約と録画」タブ (予約と録画の2列)                          | **「録画」タブの1本の一覧**。上が録れたものと録画中、赤い「いま」の線、下がこれからの予約。カレンダー・状態・絞り込み (予約・録画中・未視聴と、競合・失敗などの見てほしいこと)・表示の切り替えは右のサイドバー (狭い画面は一覧の頭、スマホは下のタブの上の1行) |
| 「チューナー」タブ (`/tuners`)                                | 設定の「受信」。空きと設定は「チューナー」の1つの表に、スキャンとロゴは「チャンネル」の表 (見出しの行と、局ロゴ・CMロゴの列) に                                                                                                                                |
| スマホの下のタブ「設定」                                      | 「その他」の中 (ルール・設定・テーマ)。「検索」のタブが増えました                                                                                                                                                                                              |
| 設定の1枚の画面                                               | 4つのグループの画面: **録画**・**受信**・**連携**・**その他** (`/settings/general` など)。節は上から積んであり、左の目次で飛べます                                                                                                                             |
| ヘッダーのログアウト                                          | 設定の「その他」の「ログイン」                                                                                                                                                                                                                                 |
| 設定の「互換モードで再生」                                    | 再生画面の ⚙ の「互換モード」                                                                                                                                                                                                                                  |
| 操作バーのバックグラウンド再生・CM スキップ・音声・コーデック | 再生画面の ⚙ (再生の設定) に1つにまとめました。速さ・字幕のオン/オフ・小窓・全画面は操作バーのまま                                                                                                                                                             |
| 設定の「GPU」                                                 | 設定の「録画」の「エンコード」の、映像コーデックの行                                                                                                                                                                                                           |
| ホーム・番組表・ルールの検索欄                                | ヘッダーの真ん中の全体の検索 (`/search`)。下の「検索」                                                                                                                                                                                                         |
| ルールの画面の書く欄と「この条件で録れる番組」                | 検索の画面の「ルールとして保存」(`/search`。ルールを直すときは `/search?rule=<ID>`)。ルールの画面 (`/rules`) は一覧と管理だけになりました                                                                                                                      |

前の URL (`/tuners`・`/settings/tuners`・`/rules?edit=<ID>` など) は、移った先へ送ります。ブックマークはそのままで構いません。

## 無くなった設定

- **`FPS_SURVIVE`** — コマ数 (30 / 60) の決め方を変えたので要らなくなりました。書いてあっても読みません。
  消して構いません (下の「コマ数の判定」)

## 既定が変わった設定

- **`ENCODE_CONCURRENCY`** — 録画のエンコードを同時に進める本数の既定を 1 から 2 にしました。同梱の compose と chart はもともと 2 です。1 本ずつにしたいときは `1` を書いてください

ほかの環境変数は変わっていません ([config.md](config.md))。

## 上げると変わるもの

- **ルールのジャンル条件は外れます** — 上げて最初に起動したとき、今あるルールのジャンルの指定を全部外して
  全ジャンルにします。ジャンルは局によって付け方が揺れ、同じシリーズでも回によって違うことがあり、絞ると録り逃すためです。
  予約は起動直後にいつもどおり組み直します。キーワードも局も無く、ジャンルだけで作っていたルールは条件が無くなり、
  何も録らなくなります。必要なら作り直してください (ジャンルは検索の画面の「ルールとして保存」で今までどおり選べます)。
  録画や番組から「ルールを作る」ときも、ジャンルは入れません

## 新しくできたこと

- **ほかの端末からもログアウト** — 設定の「その他」から、いま使っている端末のほかのログインを全部終わらせます。
  なくした端末を止めるときに ([auth.md](auth.md))。テレビのアプリは「連携」の「テレビのアプリ」で1台ずつ取り消します
- **字幕の言語** — 字幕に言語が2つ以上あれば、⚙ の「字幕」で選べます (ライブ・追っかけ・観る画面)。選んだ言語は端末ごとに覚えます
- **アンビエントモード** — 映像の縁の色を外へ延ばし、周りの地に薄く敷きます (観る画面とライブ。⚙ でオン/オフ)
- **ルールの一覧** — 録画の一覧と同じ2段の行で、条件・次の放送・予約と録画の数・最後に録れた日を並べます。
  絞り込み (有効・無効・次の放送なし・競合あり)・並べ替え・集計は右のサイドバーに。スイッチで有効/無効、2回押しで削除。行を押すと検索の画面で直せます
- **コマ数の判定** — フィールドを比べて素材を見分けるようにしました。アニメの OP のような動きの激しい場面で
  60コマに倒れていたのが直ります ([encode.md](encode.md))
- **CM の判定** — CM に挟まれた短い所 (次回予告と提供など) の頭の、ロゴを出したまま流れる局の告知も CM にします ([cm.md](cm.md#境目の決め方))
- **見た目** — カードをやめ、サイドバーは地と同じ面で端に付けました。暗いテーマの地をほぼ黒に、ボタンを主の色で塗らない形に、
  動きを短く (80ms) しました。番組表の操作は細い1行に、観る画面とライブの番組の中身は右端のサイドバーに。
  ヘッダーと下のタブは中身の上に浮かせています。スマホでは下のタブがある画面のヘッダーを隠します。決まりは [design.md](design.md)
- **検索** — 番組表・録画・予約・ルールを1つの言葉でまとめて探します。広い画面ではヘッダーの真ん中 (`/` か Ctrl+K)、
  スマホは下のタブの「検索」から。打つそばから候補と結果が変わり、結果の URL (`/search?q=…`) はそのまま渡せます
- **検索からルールを作る** — 検索の画面の右 (スマホは下の「ルールとして保存」) で、探した言葉からそのままルールにできます。
  条件を変えると、結果の番組ごとに「録る / 録らない (同じ回・除外・局) / 予約済み」がすぐ変わります。番組表や録画の「ルールを作る」もここに来ます

画面ごとの説明は [screens.md](screens.md)。
