# 見た目の決まり

画面の見た目の決まりです (手を入れる人向け)。言葉の決まりは [writing.md](writing.md)、画面ごとの説明は [screens.md](screens.md)。

**合言葉: 塗らない。囲みすぎない。浮かせすぎない。でも、ちゃんと伝わる。**

## 考え方

**ふだんは平らにして、強弱が要るところにだけ奥行きを付けます。**

- 通常の状態は、アイコン・字・余白・揃えだけで組みます。要らない地の色・枠・影・飾りは付けません。
  いつもカードのように浮いて見える要素は作りません
- 奥行きは素材の飾り (透かし・ぼかし・光の反射) ではなく、余白・配置・字の濃さ・線・ごく薄い影・押したときの反応で出します
- **塗りつぶして目立たせるのではなく、見た目の順位で意味を伝えます。** 選んでいる・オンになっている、を要素ごと強い色で塗るのを標準にしません。
  色は無くさず、使う場所と役目を決めて使います
- 通常の要素・選んでいる要素・操作している要素を同じ強さで見せません。画面のすべてに影や立体感を足すことはしません

## 見た目の役目

1 つの見た目に複数の意味を持たせません。選んでいる・オン・指を乗せた・焦点・押している、を分けて作ります。

| 見た目                                | 役目                                                        |
| ------------------------------------- | ----------------------------------------------------------- |
| 余白・配置・揃え                      | 情報の組み立てと、基本の順位                                |
| 文字の幅いっぱいの下線 (横に並ぶもの) | いまいる場所・選んでいるもの (ヘッダーのナビ・種別・日付)   |
| 左の縦線 (縦に並ぶもの)               | いまいる場所・選んでいるもの (サイドバー・局・開いている行) |
| アイコンの下の短い線                  | 機能がオン (プレイヤーの字幕・音を消す・ループなど)         |
| 主の色の字・アイコン                  | 線と組んで、選んでいる・オンを補う                          |
| 行全体のごく薄い地                    | 指を乗せた行と、そのまとまり (情報と右端のボタンが同じ行)   |
| 面と 2 段の影 (浮かせる)              | 主のボタン (1 画面に 1 つか 2 つ)。ほかのボタンは平ら       |
| 凹み (少し暗い地と内側の影) と下の線  | 字を打つところ。打っている間は下の線を主の色の 2px          |
| ボタンそのものの色の変化              | 取消・削除など、押そうとしている操作                        |
| ごく小さな沈み込み                    | 押した手応え                                                |
| 近い影と遠い影 (2 段)                 | 浮かぶもの (メニュー・ダイアログ・検索の候補)               |
| 端から消えていく黒い影                | 映像の上で押すものを読ませる (操作バー・右の列)             |
| 外側の線 (2px)                        | キーボードで触っているところ (焦点)                         |
| 状態の色 (赤・緑・黄)                 | 録画中・問題・成功・注意。バッジ・通知・進み具合のバー      |

**下線は長さで意味を分けます。** 文字の幅いっぱいの線は「いまいる場所・選んでいるもの」、アイコンの下の短い線は「機能がオン」です。

## 色

| 色                                                      | 使うところ                                          |
| ------------------------------------------------------- | --------------------------------------------------- |
| 主の色 (`--pico-primary`)                               | 線 (下線・左の縦線・オンの短い線)・焦点の線・リンク |
| 淡い地の上で字にする主の色 (`--dp-primary-text`)        | 選んでいるもの・オンの字とアイコン・土曜            |
| 本文の字                                                | 題名・本文                                          |
| 控えた字 (`--dp-muted`)                                 | 説明・補足 (日時・局・状態)・選んでいないナビ       |
| 録画の赤 (`--dp-rec`)・緑 (`--dp-ok`)・黄 (`--dp-warn`) | 状態だけ。選んでいる印には使わない                  |

状態の色を**字やアイコンにするときは `-text` の側** (`--dp-rec-text`・`--dp-ok-text`・`--dp-warn-text`) を使います。
淡い地の上で 4.5:1 になるよう濃くした段で、地の色やバー・点に使う側とは別です。

**読める濃さ**: 字は地に対して 4.5:1 以上、線とアイコンは 3:1 以上にします。明るいテーマと暗いテーマの両方で、
指を乗せた地・選んだ行の上でも確かめます (`tests/e2e/48-link-hover`・`45-buttons` が見ています)。

**色だけに頼りません。** 選んでいるものは線と太字、オンは線、状態は印 (点・✕・⚠) と言葉を添えます。

## いまいる場所・選んでいるもの

ナビ・サイドバー・タブ・一覧の中の選択は、**塗らずに線と字で示します。**

- **通常**: 地は塗らない。字は本文 (ナビは控えた字)。影は付けない
- **選んでいる**: 主の色の線 (横に並ぶものは下線、縦に並ぶものは左の縦線) と、主の色の太字。**行全体を塗らない**
- **指を乗せた**: 地をごく薄く変える (`--dp-hover-soft`)。影は付けない。選んでいる印とは混ぜない (一時的な反応として扱う)
- 枠のあるチップは、枠を主の色にして字を主の色の太字に
- 番組表の日付の土日は、選んでいても土日の字の色のまま (線は主の色)

**例外は作りません。** 決まりは部品ごとに変えず、どこでも同じに当てます。カレンダーも同じで、選んでいる日は主の色の下線と字、
行のある日は控えた色の点、今日は太字と赤い点 (「いま」の線と同じ赤。行があっても点は 1 つ) です。**1 つの意味に印は 1 つ**にし、
点と字の濃さのように同じことを 2 つで言いません。

選んでいる行に奥行きを足すときは、行が別のカードに見えない程度のごく薄い地か影にとどめます。目的は飾りではなく、いまいる場所を見つけやすくすることです。

## プレイヤーのオン・オフ

字幕・音を消す・ループなどの切り替えのボタン (`ControlButton` の `on`) です。サイドバーの線が「いまどこにいるか」なのに対し、
こちらの短い線は「機能がオンか」です。

- **ボタンは塗りません。** 明るい映像の上でも読めるよう、ボタンごとではなく**並び全体の裏に影を敷きます**
  (下の操作バーは下の端から、右の列は舞台の高さいっぱいに右の縁から、濃い黒が消えていく。`ControlBar`)。
  アイコンと字にも小さな影を付けます。指を乗せた・キーボードで触っているボタンだけ、ごく薄い地を出します
- **オフ**: アイコンは白。線は無し
- **オン**: アイコンを空色 (`#7dd3fc`。暗い影の上で読める明るさの主の色) に。アイコンの下に短い空色の線。**ボタン全体を塗らない**
- **戻せないものの 2 回目** (削除の確認) と、「今」へ張り付いている「ライブ」「最新」は、赤い字と赤い短い線
- オンは押した後も残し、いまの設定がいつでも分かるようにする
- 読み上げには `aria-pressed` で、マウスには `title` で名前を渡す (アイコンだけに頼らない)

## 何行かある一覧

録画・予約・ルールのように、1 件が題名・説明・補足の 2〜3 行で、右端に取消や削除が並ぶ一覧です。

- **ふだんは枠・地・影を付けません。** 1 件ずつは余白で分けます。区切りの線も標準にしません
- **1 件の中は近づけ、件と件の間は離します。** 題名がいちばん強く、説明はそれより控えめ、日時・局・状態はさらに控えめ。
  左のサムネイルやアイコンと、字の始まりを件ごとに揃えます
- **右端のボタンはその件の中に置きます。** 題名や説明との位置を件ごとに同じにし、ボタンそのものには強い地や影を常に付けません
- **指を乗せたら件全体の地をごく薄く変えます** (題名だけでなく、右端のボタンまで)。枠のない件と、その件のボタンが同じまとまりだと分かるように。
  強い影や枠は足しません
- **ボタンそのものの反応は件の反応と分けます。** 削除に指を乗せたときだけ字とアイコンを警告の色にする、など。
  削除は 2 回押しで確かめます (1 回目で「削除を確定」に変わる。[writing.md](writing.md#同じことは同じ文言で))
- **指で押す端末では、指を乗せた反応がありません。** それが無くても分かるよう、件の間の余白とボタンの置き場を一定にし、
  押せる範囲を確保します (行は 64px、指の端末では 72px。行の中のボタンは高さ 40px 以上)。キーボードでは焦点の線で示します

## ボタン

**強弱は塗りや枠ではなく、影のあるなしで付けます** (`app.css` の「ボタン」。色と形は `--dp-btn-*` で決め、画面ごとに塗り直さない)。

- **主** (クラス無し・`.small`・`.xs`・`.save` など): 面 (`--dp-btn-solid`) と 2 段の影 (`--dp-raise`) で浮かせ、字は本文の色の太字。
  主の色では塗らない。1 画面に 1 つか 2 つ
- **控え** (`.secondary`・`.outline`) と **字だけ** (`.ghost`): 平ら。地も枠も影も無い。アイコンと字で押せると分かるようにし、乗せたら薄い地
- **戻せないもの**: 1 回目 (`.outline.danger`) は控えと同じで、乗せたときだけ赤い字。確定 (`.danger`) は浮かせて赤い字
- **入っている切り替え** (`aria-pressed="true"`): ほかの選んでいるものと同じく、主の色の字と短い下線。塗らず、浮かせない
- 角は行やメニューと同じ `--dp-radius`。アイコンだけのボタンは角の丸い正方形
- 画面ごとに自前の見た目を持つボタン (行・メニューの項目・タブ・チップ・リモコン) は名前のクラスを持たせ、浮かせない

## 入力欄

**奥行きで役目を分けます。押すもの (主のボタン) は浮かせ、読むもの (本文・行) は平ら、書き込むもの (入力欄) は凹ませます。**

入力欄は少し暗い地 (`--dp-input-well`) と上の縁の内側の影 (`--dp-input-inset`) でくぼませ、枠では囲みません (`app.css` の「入力欄」)。
境目は下の線 (`--dp-input-line`。地に対して 3:1 以上) で示します。凹みの影だけでは境目の濃さが足りません (WCAG 1.4.11)。
字を打っている間は下の線を主の色の 2px にして、外側の焦点の線は引きません。ヘッダーの検索の欄も同じです。

## 押した瞬間

押している間の反応と、押した後に残る状態を分けます。

- **押している間**: 主のボタンは 1px 沈めて影を浅くする (平らなボタンは地を一瞬だけわずかに変える)。強い影や大きな動きは使わない
- **押した後**: オン・オフに合わせて字とアイコンの色、線を変える。押している間だけの地や動きは戻す

動きは「押した手応え」を、色と線は「いまの状態」を伝えます。

## 浮かぶもの

メニュー・検索の候補・ダイアログ・画面の下のタブは、**透かさない面と影で浮かせます。縁は付けません。**
透かし・ぼかし (`backdrop-filter`)・光の反射は、どこにも使いません (映像の上のメニューも同じ)。

- 面は `--dp-pop` (メニュー・検索の候補)・`--dp-surface` (ダイアログ)。映像の上のメニューはテーマにかかわらず暗い面
- 影は近い影と遠い影の 2 段 (`--dp-shadow-pop`。下の端に貼り付くタブは上向きの `--dp-shadow-up`)
- ヘッダーは本文と同じ地に、透かさずに置きます
- 透かしを減らす設定 (`prefers-reduced-transparency`) では、映像の上の影を濃くします (端へ消えていく形は残す)

## 作り方

- 状態は `color`・`border`・疑似要素 (`::before`・`::after`) の線で作ります。線は押す範囲の内側に引き、高さを変えません
- 影は要るところだけ、控えめな `box-shadow` で
- 動きは短く (`--dp-duration` の 80ms)、`transition` と小さな `transform` だけ。いつも動き続けるものは、いま動いていることを示す印 (録画中の点) だけ
- 選んでいる印を前の場所から滑らせるときは `#lib/motion.svelte.js` の `slide`
- 焦点は `:focus-visible` に外側の 2px の線 (`app.css`)。マウスで押したときは出さない
- 動きを減らす設定 (`prefers-reduced-motion`) では動きを止める (`app.css` の最後)
- 角は `--dp-radius`。地・線・字の色は `app.css` の `--dp-*` から選び、画面ごとに新しい色を作らない
