# 見た目の決まり

画面の見た目の決まりです (手を入れる人向け)。言葉の決まりは [writing.md](writing.md)、画面ごとの説明は [screens.md](screens.md)。

**合言葉: 塗らない。囲みすぎない。浮かせすぎない。でも、ちゃんと伝わる。**

書き方: 大きな決まり (1 章) → 章ごとの決まり (太字の 1 文) → 細かい決まり (箇条) → 例 → 例外。
決まりはどこでも同じにし、部品ごとの例外は作りません。例外は、理由が書けるものだけをその決まりのすぐ下に書きます。
決まりに揃っていない所 (直す予定のもの) は、例外ではなく最後の「今とのずれ」に書きます。

## 1. 考え方

大きな決まりは 5 つです。2 章から下は、どれもこのどれかから来ています。

1. **ふだんは平らに。** アイコン・字・余白・揃えだけで組み、要らない地の色・枠・影・飾りは付けない
2. **強弱は塗りではなく、見た目の順位で。** 選んでいる・オンを強い色で塗らない。色は役目を決めて使う
3. **奥行きは層で。** Liquid Glass から層の考え方だけを借りる。ぼかし・屈折・光の反射は使わない (CSS では重い)
4. **1 つの意味に印は 1 つ。** 同じことを 2 つの印で言わず、1 つの見た目に 2 つの意味を持たせない
5. **動きは CSS で。** JS では動かさない。動きは「何が起きたか」を伝えるためだけに使う

## 2. 3 つの層

元: 3 奥行きは層で

**置くものは地・件の面・操作の層の 3 つの高さに分け、それより上は作らない。**

| 層           | 置くもの                                                                                                                                                | 面                                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **地**       | 1 行の並び (サイドバー・設定の項目)・映像                                                                                                               | 平ら。線も影も付けない (`--dp-bg`)                                                                                      |
| **件の面**   | 1 件が 2〜3 行ある一覧の件 (録画・予約・ルール・検索の結果)・番組表のマス                                                                               | 透かさない面 (`--dp-item`)。明るいほうは白とごく薄い影、暗いほうは地より一段明るい。縁は無し                            |
| **操作の層** | ヘッダー・その下に貼り付く操作の 1 行・下のタブ・画面の下の主の操作・貼り付いた日付の見出し・番組表の局名と時の列と「いま」の時刻・メニュー・ダイアログ | 面 (`--dp-float` か `--dp-pop`) と 2 段の影 (`--dp-shadow-pop`)。隙間を詰めて並ぶものは近い影だけ (`--dp-shadow-tight`) |

- **浮いたものの上に、さらに浮いたものを重ねない。** 中のボタンは平らで、主の操作は太字だけ
  - 例: 件の面・メニュー・ダイアログ・下から出す一枚・浮いた 1 行の中のボタン
- **主の操作は色ではなく層で示す。** 主のボタンを操作の層に乗せ、ほかの操作は字とアイコンだけで平ら
- 隙間を詰めて並ぶものは、近い影だけにする (遠い影が隣に掛かって段々に見えないように)
  - 例: ヘッダーとその下の操作の 1 行、番組表の局名

## 3. 浮かせ方

元: 1 ふだんは平らに・3 奥行きは層で

**浮かせるのは、動く中身の上に重なるものだけ。** 裏に何も来ないうちは平らに置く。

- **中身が裏に入ったときだけ、面と影を出す** (巻いた量に合わせて出る。仕組みは「動き」)
  - 例: ヘッダー (広い画面)。面は `--dp-float` (メニューの面を 92% 残す)、字は 4.5:1 以上、端から離した角丸の面
  - 例: ヘッダーの下に貼り付く操作の 1 行。番組表・ホーム (640〜999px)・ルール (768〜999px)・設定の節の行 (640〜767px)。
    形はヘッダーと同じ (`app.css` の `--dp-bar-*`)、ヘッダーとの間は `--dp-bar-gap` (0.25rem)。この 1 行がある間はヘッダーも近い影にそろえる
  - 例: 日付の見出し。貼り付いて行がその裏を流れるときだけ、小さなカプセル (`scroll-state(stuck: top)`)
  - 例外: 下のタブ (狭い画面) はいつも浮いたまま (いつも中身が裏を流れる)。同じ操作の 1 行も、スマホでは下のタブのすぐ上にいつも浮かせる
  - 例外: 知らないブラウザと動きを減らす設定の端末では、いつも浮いた形 (平らだと裏の中身と重なって読めない)
- **透かすのは、裏が動くものだけ。** ぼかさない
  - 例: 映像の上のメニューは、テーマにかかわらず暗い面で映像を透かす (地を 86% 残す)
  - 例: ホーム画面から開いた iPhone のステータスバーは、暗いテーマのときだけ透かす (地を 85% 残した面)
  - 例外: 明るいテーマのステータスバーは地の色で塗ったまま (時刻の字がいつも白いため)。ブラウザのタブでは色 (`theme-color`) を合わせるだけ
  - 例外: 透かしを減らす設定 (`prefers-reduced-transparency`) では透かさず、映像の上の影を濃くする
  - ページの中で開くメニュー・検索の候補・ダイアログは、後ろが動かないので透かさない
- **中身を読んでいる間は引っ込む。** 狭い画面の下のタブ (とその上の 1 行) は、下へ送ると隠れ、戻すと出る
  - 例外: 番組表では引っ込めない (表の高さが下のタブの上までで決まっている)。広い画面のヘッダーも引っ込めない (検索を見せたまま)

画面ごとの組み方 (上の決まりの例):

- **一覧の画面 (録画・ルール・設定・検索)** はページごと巻き、中身がヘッダーの裏を流れる。頭に `--dp-header-space` を空け、スクロールバーは窓の右端に出る。
  サイドバーは地のまま、ヘッダーの下に貼り付けて動かさない (あふれたらサイドバーの中で巻く)
- **観る画面**は箱をヘッダーの下から始める (`+layout.svelte` の `.shell.fill`。裏まで伸ばすと箱のスクロールバーだけが透ける)。窓が巻けないので、ヘッダーはいつも平ら
- **番組表 (768px 以上)** は表をヘッダーの裏まで伸ばし、操作の 1 行と局名の行をその下に貼り付ける。ヘッダーは窓ではなく表の巻いた量で浮く
  (表の箱の時間の軸 `--guide` を `timeline-scope` で外枠まで見せる)。768px より狭い画面では、表をヘッダーの下から始める
  - 表のスクロールバーは出さない (ヘッダーの裏に透ける)。つかむ・ホイール・キー・指で動く
  - 局名は局ごとの角丸の面 (列と一緒に横へ動くので、1 本につながった面にしない)
  - 時の列は操作の層。マスがその裏を流れ、影はマスの側 (右) にだけ落とす

## 4. 印の意味

元: 2 強弱は見た目の順位で・4 1 つの意味に印は 1 つ

**印は意味ごとに 1 つの見た目に決め、どこでも同じ意味で使う。**

| 見た目                                | 意味                                                                          |
| ------------------------------------- | ----------------------------------------------------------------------------- |
| 文字の幅いっぱいの下線 (横に並ぶもの) | いまいる場所・選んでいるもの (ヘッダーのナビ・種別・日付・チップ)             |
| 左の縦線 (縦に並ぶもの)               | いまいる場所・選んでいるもの (サイドバー・局・開いている行・メニューの選択肢) |
| 短い下線                              | 機能がオン (プレイヤーの字幕・音を消す・番組表の「サブch」など)               |
| 主の色の太字                          | 線と組んで、選んでいる・オンを補う                                            |
| ごく薄い地 / 件の面を一段変える       | 指を乗せた (地の上の行 / 件)                                                  |
| 外側の 2px の線                       | キーボードで触っているところ (焦点)                                           |
| ごく小さな縮み                        | 押した手応え                                                                  |
| 状態の色 (赤・緑・黄)                 | 録画中・問題・成功・注意。バッジ・通知・進み具合のバー                        |
| 淡い地のカプセル (バッジ)             | 状態だけ (録画中・有料・無効・競合)                                           |

- **下線は長さで意味を分ける。** 幅いっぱいは「選んでいる」、短い線は「オン」
- **1 つの部品に線は 1 本。**
  - 例: 自前の線を持つタブ・チップには、入っている切り替え (`aria-pressed`) の共通の短い下線を重ねない
- **事実はバッジにしない。** 番組の事実 (ジャンル・映像・音声) は、一覧の補足と同じく控えた字を「・」でつなぐ

## 5. 色

元: 2 強弱は見た目の順位で

**色は役目ごとに決め、選んでいる印と状態で混ぜない。**

| 色                                                      | 使うところ                                           |
| ------------------------------------------------------- | ---------------------------------------------------- |
| 主の色 (`--pico-primary`)                               | 線 (下線・左の縦線・オンの短い線)・焦点の線・リンク  |
| 淡い地の上で字にする主の色 (`--dp-primary-text`)        | 選んでいるもの・オンの字とアイコン・土曜             |
| 本文の字                                                | 題名・本文                                           |
| 控えた字 (`--dp-muted`)                                 | 説明・補足 (日時・局・状態)・押せない日 (カレンダー) |
| 録画の赤 (`--dp-rec`)・緑 (`--dp-ok`)・黄 (`--dp-warn`) | 状態だけ。選んでいる印には使わない                   |

- **読める濃さを保つ。** 字は 4.5:1 以上、線とアイコンは 3:1 以上。両方のテーマで、指を乗せた地・選んだ行の上でも確かめる (e2e `48-link-hover`・`45-buttons`)
  - 例: 状態の色を字やアイコンにするときは `-text` の側 (`--dp-rec-text` など。淡い地の上で 4.5:1 になるよう濃くした段)
- **色だけに頼らない。** 選んでいるものは線と太字、オンは線、状態は印 (点・✕・⚠) と言葉を添える
- **ブラウザが描く部品もテーマに合わせる** (`color-scheme`)
  - 例: プルダウンの一覧・スクロールバー・日付の選び方が、暗いテーマで白く出ない
- **映像の上はテーマで変えない** (舞台はいつも黒い)
  - 例: 字 `--dp-on-video`・控えた字 `--dp-on-video-muted`・オン `--dp-on-video-on` (空色)・戻せないものの 2 回目と「今」 `--dp-on-video-danger` (赤)・
    メニューの面 `--dp-video-menu`・覆い `--dp-video-veil`

## 6. 部品

元: 1〜4 の全部。部品ごとに、上の決まりをどう当てるかを書く

### 選んでいるもの (ナビ・サイドバー・タブ・チップ・カレンダー)

**塗らずに、主の色の線と太字で示す。**

- 通常は地を塗らず、字は本文 (ナビも薄くしない)
- 選んでいるものは主の色の線 (横は下線、縦は左の縦線) と主の色の太字。行全体を塗らない
  - 例: チップは枠も地も付けず、入っているものは主の色の太字と下線
  - 例: カレンダーの選んでいる日は下線と字。行のある日は本文の字、無く押せない日は控えた字、今日は赤い点 (「いま」と同じ赤)
  - 例外: 番組表の日付の土日は、選んでいても土日の字の色のまま (線は主の色)
- 指を乗せたら地をごく薄く (`--dp-hover-soft`)。選んでいる印とは混ぜない

### 何行かある一覧

**1 件ずつ件の面に乗せ、線で区切らない。**

- 件の間は `--dp-list-gap` (6px)。1 件の中は近づけ、件の間は離す
- 題名がいちばん強く、説明・補足 (日時・局・状態) の順に控える。サムネイルと字の始まりを揃える
- 右端のボタンはその件の中に置き、位置を件ごとに同じにする。ボタンは平ら
- 反応は件とボタンで分ける。件は面を一段変え (`--dp-item-hover`)、ボタンは自分だけ (削除に乗せたときだけ赤い字)
  - 例: 選んでいる・開いている件は左の縦線と太字で、面は塗り替えない
  - 例: 削除は 2 回押しで確かめる ([writing.md](writing.md#同じことは同じ文言で))
- 指の端末でも押せる範囲を保つ。行は 64px (指の端末では 72px)、行の中のボタンは高さ 40px 以上
- 件の中の線は面の端に付ける
  - 例: 進み具合のバー (録画中・エンコード・ダウンロード) は件の面の下端いっぱいに付け、面の角で切り落とす
- 「いま」は地に置き、線は引かない。赤い点と赤い太字の時刻、すぐ後ろに控えた字で次の録画までの一言。左は日付の字にそろえる

### ボタン

**強弱は層と字の太さで付け、色では塗らない。** 色と形は `app.css` の `--dp-btn-*` で決め、画面ごとに塗り直さない。

- **主** (クラス無し・`.small`・`.xs`・`.save` など): 操作の層の面 (`--dp-float`) と影のカプセルで、字は本文の色の太字
  - 1 画面に 1 つか 2 つ。保存などは画面の下に置き、中身を送っても見えたままにする
  - 例外: 浮いたものの中では浮かせず太字だけ (`--dp-btn-solid` と `--dp-btn-lift` を消す。「3 つの層」)
- **控え** (`.secondary`・`.outline`)・**字だけ** (`.ghost`): 平ら。地も枠も影も無く、乗せたら薄い地
- **戻せないもの**: 1 回目 (`.outline.danger`) は控えと同じで乗せたときだけ赤い字。確定 (`.danger`) は主と同じ層で赤い字 (赤では塗らない)
- **入っている切り替え** (`aria-pressed="true"`): 主の色の字と短い下線。塗らず、浮かせない
- 形はカプセル (`--dp-radius-full`)、アイコンだけなら円
  - 例外: 自前の見た目を持つもの (行・メニューの項目・タブ・チップ・リモコン) は名前のクラスを持たせ、浮かせない

### 入力欄

**線も凹みも付けず、平らな面だけで示す。**

- 面 (`--dp-field`) は下を透かす薄い色で、地・件の面・ヘッダーのどれの上でも一段濃い (暗いほうは明るい) 面になる
- ラベルはいつも見せる (中の字だけの案内に頼らない)。打っている間は外側の 2px の主の色の線
  - 例外: 面と地の差は 1.24:1 (明るい)・1.31:1 (暗い) で、境目の 3:1 (WCAG 1.4.11) には届かない。ラベルと焦点の線で補う

### メニュー・ダイアログ・検索の候補

**どのメニューも同じ形にし、縁を付けず影だけで浮かせる。**

- 形は箱の内側の余白 8px・項目の間 2px・項目の余白 8px × 12px。色だけ層で変わる (ページは `--dp-pop`、映像の上は暗い面、ダイアログは `--dp-surface`)
  - 例: ページのメニュー・映像の上のメニュー (再生の設定・速さ)・プルダウンの一覧
- 中のまとまりも線で分けず、余白と、要るときは控えた字の見出しで分ける
- 横に開く子メニューは使わない (指の端末には乗せる操作が無く、よく使う項目までひと手間増える)
- プルダウンの開いた一覧も、マウスの画面ではメニューと同じ姿 (`appearance: base-select`)
  - 例外: 指の端末と、知らないブラウザはブラウザ・OS の選び方のまま (画面の下から大きく出て、指で選びやすい)

### 番組表のマス

**マスは淡い面にし、状態は小さな印と言葉で示す。**

- マスは面 (地にジャンルの色をごく淡く混ぜる)。枠は引かない
- ジャンルは時刻の前の小さな点 (ジャンルのメニューの見本も同じ点)。左の太い線は使わない (左の縦線は「選んでいる」の印)
- 予約の状態は時刻の後ろの印と、説明の代わりの太字の言葉。印は説明の行が切れる短いマスでも見える
  - 例: 予約済みは主の色の ✓、録画中は赤い ●、競合は赤い ⚠ (競合を予約済みと同じ青にしない)
- 塗るのはいま動いている録画中だけ (録画の赤をごく淡く)
- 放送が過ぎた所は、マスの上から地の色を重ねて沈める。表を横切る「いま」の線は引かず、時の列に「いま」の時刻のカプセルだけを置く (分だけ)
  - 例: 終わった番組はマス全体、放送中は頭からいまの位置まで浅く

### 映像の上の操作

**ボタンは塗らず、オンは空色の短い線で示す。**

- 明るい映像でも読めるよう、並び全体の裏に端から消えていく黒い影を敷く (`ControlBar`)。アイコンと字にも小さな影
- オフは白、オンは空色のアイコンと下の短い空色の線。オンは押した後も残し、いまの設定がいつでも分かるようにする
  - 例外: 戻せないものの 2 回目と、「今」へ張り付いている「ライブ」「最新」は赤い字と赤い短い線
- 指を乗せた・キーボードで触っているボタンだけ、ごく薄い地を出す
- 読み上げには `aria-pressed`、マウスには `title` で名前を渡す

## 7. 動き

元: 5 動きは CSS で

**動きは CSS だけで作り、「何が起きたか」を伝えるときだけ動かす。** 時間と曲線は `app.css` の名前から選び、画面ごとに数字を書かない。

| 時間                  | 長さ  | 使うところ                                                                         |
| --------------------- | ----- | ---------------------------------------------------------------------------------- |
| `--dp-duration`       | 120ms | 色・地・影の移り変わり、押して縮む                                                 |
| `--dp-duration-enter` | 240ms | 開く・出てくる (メニュー・ダイアログ・番組の詳細・下から出す一枚・件・画像)        |
| `--dp-duration-move`  | 300ms | 場所が動く (選んでいる印が滑る・浮いた 1 行の出し入れ・スイッチ・縮んだものが戻る) |
| `--dp-duration-exit`  | 150ms | 閉じる・消える (待たせないよう短く)                                                |

曲線は 3 つ: ふつうは `--dp-ease` (終わりをゆっくり)、開く・滑る・戻るは `--dp-ease-spring` (少しだけ行き過ぎて戻るばね)、閉じるは `--dp-ease-exit` (頭をゆっくり)。

- **開くものは、少し小さく少しずれた透明な姿からばねで出る** (`@starting-style`)。閉じるときは短く引っ込む
  - 例: メニュー・プルダウンの一覧・ダイアログ・番組の詳細
- **選んでいる印は、前の場所から滑る。** 並びの疑似要素 1 本を CSS のアンカーで選んでいる項目に付ける。開いた直後はその場に出る
  - 例: タブの下線・ヘッダーのナビの下線・下のタブの印
  - 例外: アンカーを知らないブラウザは項目の中に線を引く (滑らない)
- **浮くものは、巻いた量に合わせて面と影が出る** (`animation-timeline: scroll()`。番組表では表の箱の軸 `--guide`)。巻けない短いページでは平らなまま
  - 例: ヘッダーとその下の操作の 1 行
- **押すと主のボタンは少し縮み (97%)、離すとばねで戻る。** 押した後の状態は色と線で示す
- **件は透明度だけでふわっと出る。** 場所は動かさず、読んでいる所をずらさない
  - 例: 読み込めた画像も同じ (`#lib/motion.svelte.ts` の `fadeIn` は読み込めた合図で印を付けるだけ)
- **動き続けるのは、いま動いていることを示す印だけ**
  - 例: 録画中の点・動いているバーの光
- 動きを減らす設定 (`prefers-reduced-motion`) では、時間を全部 0 にして止める (`app.css` の最後)

## 8. 作り方

元: 1〜5 の全部。CSS での書き方

**値は `app.css` の名前から選び、画面ごとに新しい値を作らない。**

- 地・線・字の色は `--dp-*` から選ぶ
- 状態は `color` と疑似要素 (`::before`・`::after`) の線で作る。線は押す範囲の内側に引き、高さを変えない
- 影は要るところだけ、控えめな `box-shadow` で
- 焦点は `:focus-visible` に外側の 2px の線。マウスで押したときは出さない
- 角は入れ子でそろえる (外の角 = 内の角 + 間の余白)
  - 例: ボタンと下に浮く 1 行 (スマホ) はカプセル、ヘッダーとその下の操作の 1 行は `--dp-bar-radius` (中の欄の角 + 余白)、
    行・入力欄は `--dp-radius`、件は `--dp-item-radius`、メニューの項目は箱の角 − 内側の余白
