# 見た目の決まり

画面の見た目の決まりです (手を入れる人向け)。言葉の決まりは [writing.md](writing.md)、画面ごとの説明は [screens.md](screens.md)。

**合言葉: 塗らない。囲みすぎない。浮かせすぎない。でも、ちゃんと伝わる。**

## 考え方

**ふだんは平らにして、強弱が要るところにだけ奥行きを付けます。**

- 通常の状態は、アイコン・字・余白・揃えだけで組みます。要らない地の色・枠・影・飾りは付けません。
  いつもカードのように浮いて見える要素は作りません
- 奥行きは素材の飾り (ぼかし・光の反射) ではなく、余白・配置・字の濃さ・線・ごく薄い影・押したときの反応で出します
- **塗りつぶして目立たせるのではなく、見た目の順位で意味を伝えます。** 選んでいる・オンになっている、を要素ごと強い色で塗るのを標準にしません。
  色は無くさず、使う場所と役目を決めて使います
- 通常の要素・選んでいる要素・操作している要素を同じ強さで見せません。画面のすべてに影や立体感を足すことはしません

### 地・件の面・操作の層

目指すのは、いまの「平らで線の無い」作りの次です。Liquid Glass から**層の考え方だけ**を借ります。
ぼかし・屈折・光の反射は CSS では重いので持ち込みません。

1. **層は 3 段だけ。** 下から順に、
   - **地** (ページ): 平らで、線も影も付けない。1 行の並び (サイドバー・設定の項目・番組表のマス) と映像はここ。
     番組表の局名の行と時の列、一覧の貼り付く日付の見出しも地の色のまま (別の色の帯にしない)
   - **件の面** (`--dp-item`): 1 件が 2〜3 行ある一覧の件 (ホームの録画・予約、ルール、検索の結果)。透かさない面で、
     明るいテーマは白い面とごく薄い近い影、暗いテーマは地より一段明るい面 (影には頼らない。白い影や光は使わない)。縁は付けない
   - **操作の層** (`--dp-float`): ヘッダー・下のタブ・画面の下の主の操作・メニュー。半透明の面と強めの 2 段の影で、件の面より上に見せる
2. **操作の層は中身を少し透かす。** ぼかさず、濃い半透明の面で。後ろが動いているのが分かる程度にし、字は 4.5:1 以上を保つ。
   ただし自分で巻き取る画面 (録画・ルール・設定・番組表・観る画面) は、箱をヘッダーの下から始める (`+layout.svelte` の `.shell.fill`)。
   ヘッダーの裏まで伸ばすと、巻き取る箱のスクロールバーだけが透けて見え、行が見出しとヘッダーの隙間に透けて出る
3. **浮いたものの上に、さらに浮いたものを重ねない。** 件の面・メニュー・ダイアログ・下から出す一枚の中のボタンは平らで、主の操作は太字だけ
4. **主の操作は色ではなく層で示す。** 主の操作は操作の層 (ヘッダー・下のタブと同じ半透明の面と影のカプセル) に乗せ、
   ほかの操作は字とアイコンだけで平ら。強弱は塗りではなく、どの層にいるかで付ける
5. **角は入れ子でそろえる。** 外の角の丸み = 内の角の丸み + 間の余白
6. **操作の層は、中身を読んでいる間は引っ込む。** 下へ送ると小さくなるか隠れ、戻すと出る。動きは短く。
   引っ込むのは狭い画面の下のタブ (とその上に浮く 1 行) だけ。広い画面のヘッダーは引っ込めない (検索を見せたまま)

## 見た目の役目

1 つの見た目に複数の意味を持たせません。選んでいる・オン・指を乗せた・焦点・押している、を分けて作ります。

| 見た目                                | 役目                                                        |
| ------------------------------------- | ----------------------------------------------------------- |
| 余白・配置・揃え                      | 情報の組み立てと、基本の順位                                |
| 文字の幅いっぱいの下線 (横に並ぶもの) | いまいる場所・選んでいるもの (ヘッダーのナビ・種別・日付)   |
| 左の縦線 (縦に並ぶもの)               | いまいる場所・選んでいるもの (サイドバー・局・開いている行) |
| アイコンの下の短い線                  | 機能がオン (プレイヤーの字幕・音を消す・ループなど)         |
| 主の色の字・アイコン                  | 線と組んで、選んでいる・オンを補う                          |
| 件の面 (透かさない面・弱い影)         | 1 件が 2〜3 行ある一覧の件。乗せると面を一段変える          |
| 行全体のごく薄い地                    | 地の上の 1 行の並びで指を乗せた行                           |
| 操作の層 (半透明の面と影のカプセル)   | 主のボタン (1 画面に 1 つか 2 つ)。ほかのボタンは平ら       |
| 地より一段濃い平らな面                | 字を打つところ。打っている間は外側の焦点の線                |
| ボタンそのものの色の変化              | 取消・削除など、押そうとしている操作                        |
| ごく小さな縮み                        | 押した手応え                                                |
| 近い影と遠い影 (2 段)                 | 浮かぶもの (メニュー・ダイアログ・検索の候補)               |
| 端から消えていく黒い影                | 映像の上で押すものを読ませる (操作バー・右の列)             |
| 外側の線 (2px)                        | キーボードで触っているところ (焦点)                         |
| 状態の色 (赤・緑・黄)                 | 録画中・問題・成功・注意。バッジ・通知・進み具合のバー      |

**バッジ (淡い地のカプセル) は状態だけ** (録画中・有料・無効・競合など)。ジャンル・映像・音声のような番組の事実は囲まず、
一覧の行の補足と同じく控えた字を「・」でつなぎます。

**下線は長さで意味を分けます。** 文字の幅いっぱいの線は「いまいる場所・選んでいるもの」、アイコンの下の短い線は「機能がオン」です。

## 色

| 色                                                      | 使うところ                                           |
| ------------------------------------------------------- | ---------------------------------------------------- |
| 主の色 (`--pico-primary`)                               | 線 (下線・左の縦線・オンの短い線)・焦点の線・リンク  |
| 淡い地の上で字にする主の色 (`--dp-primary-text`)        | 選んでいるもの・オンの字とアイコン・土曜             |
| 本文の字                                                | 題名・本文                                           |
| 控えた字 (`--dp-muted`)                                 | 説明・補足 (日時・局・状態)・押せない日 (カレンダー) |
| 録画の赤 (`--dp-rec`)・緑 (`--dp-ok`)・黄 (`--dp-warn`) | 状態だけ。選んでいる印には使わない                   |

状態の色を**字やアイコンにするときは `-text` の側** (`--dp-rec-text`・`--dp-ok-text`・`--dp-warn-text`) を使います。
淡い地の上で 4.5:1 になるよう濃くした段で、地の色やバー・点に使う側とは別です。

**映像の上はテーマで変えません。** 舞台はいつも黒いので、字は `--dp-on-video` (白)、控えた字は `--dp-on-video-muted`、
オンは `--dp-on-video-on` (空色)、戻せないものの 2 回目と「今」は `--dp-on-video-danger` (赤)、
メニューの面は `--dp-video-menu`、映像を暗くする覆いは `--dp-video-veil` から選びます。

**読める濃さ**: 字は地に対して 4.5:1 以上、線とアイコンは 3:1 以上にします。明るいテーマと暗いテーマの両方で、
指を乗せた地・選んだ行の上でも確かめます (`tests/e2e/48-link-hover`・`45-buttons` が見ています)。

**色だけに頼りません。** 選んでいるものは線と太字、オンは線、状態は印 (点・✕・⚠) と言葉を添えます。

## いまいる場所・選んでいるもの

ナビ・サイドバー・タブ・一覧の中の選択は、**塗らずに線と字で示します。**

- **通常**: 地は塗らない。字は本文 (ナビも薄くしない)。影は付けない
- **選んでいる**: 主の色の線 (横に並ぶものは下線、縦に並ぶものは左の縦線) と、主の色の太字。**行全体を塗らない**
- **指を乗せた**: 地をごく薄く変える (`--dp-hover-soft`)。影は付けない。選んでいる印とは混ぜない (一時的な反応として扱う)
- チップ (小さな切り替え) は枠も地も付けず、入っているものは主の色の太字と字の幅いっぱいの下線
- 番組表の日付の土日は、選んでいても土日の字の色のまま (線は主の色)

**例外は作りません。** カレンダーも同じで、選んでいる日は主の色の下線と字です。
行のある日は本文の字、行が無く押せない日は控えた字、今日は赤い点 (「いま」の線と同じ赤) です。**1 つの意味に印は 1 つ**にし、
同じことを点と字の濃さの 2 つで言いません。

## プレイヤーのオン・オフ

字幕・音を消す・ループなどの切り替えのボタン (`ControlButton` の `on`) です。サイドバーの線が「いまどこにいるか」なのに対し、
こちらの短い線は「機能がオンか」です。

- **ボタンは塗りません。** 明るい映像の上でも読めるよう、ボタンごとではなく**並び全体の裏に影を敷きます**
  (下の操作バーは下の端から、右の列は舞台の高さいっぱいに右の縁から、濃い黒が消えていく。`ControlBar`)。
  アイコンと字にも小さな影を付けます。指を乗せた・キーボードで触っているボタンだけ、ごく薄い地を出します
- **オフ**: アイコンは白。線は無し
- **オン**: アイコンを空色 (`--dp-on-video-on`。暗い影の上で読める明るさの主の色) に。アイコンの下に短い空色の線。**ボタン全体を塗らない**
- **戻せないものの 2 回目** (削除の確認) と、「今」へ張り付いている「ライブ」「最新」は、赤い字と赤い短い線
- オンは押した後も残し、いまの設定がいつでも分かるようにする
- 読み上げには `aria-pressed` で、マウスには `title` で名前を渡す (アイコンだけに頼らない)

## 何行かある一覧

録画・予約・ルールのように、1 件が題名・説明・補足の 2〜3 行で、右端に取消や削除が並ぶ一覧です。

- **1 件ずつ件の面 (`--dp-item`。`app.css` の `.item`) に乗せます** (考え方の 1 番)。枠と区切りの線は付けません。件と件の間は `--dp-list-gap` (6px) で、
  ホーム・検索・ルールで同じにします。角は中のポスターと件の余白の入れ子 (`--dp-item-radius`)。
  設定の節どうし・表の行のような 1 行の並びは地のまま、線を引かず余白で分けます
- **1 件の中は近づけ、件と件の間は離します。** 題名がいちばん強く、説明はそれより控えめ、日時・局・状態はさらに控えめ。
  左のサムネイルやアイコンと、字の始まりを件ごとに揃えます
- **右端のボタンはその件の中に置きます。** 題名や説明との位置を件ごとに同じにし、ボタンは平ら (件の面の上で浮かせない)
- **指を乗せたら件の面を一段変えます** (`--dp-item-hover`。右端のボタンまで)。強い影や枠は足しません
- 選んでいる・開いている件は、ほかの選んでいるものと同じく左の縦線と主の色の太字。件の面は塗り替えない
- **ボタンそのものの反応は件の反応と分けます。** 削除に指を乗せたときだけ字とアイコンを警告の色にする、など。
  削除は 2 回押しで確かめます (1 回目で「削除を確定」に変わる。[writing.md](writing.md#同じことは同じ文言で))
- **指で押す端末では、指を乗せた反応がありません。** それが無くても分かるよう、件の間の余白とボタンの置き場を一定にし、
  押せる範囲を確保します (行は 64px、指の端末では 72px。行の中のボタンは高さ 40px 以上)。キーボードでは焦点の線で示します

## ボタン

**強弱は塗りや枠ではなく、層で付けます** (考え方の 4 番。`app.css` の「ボタン」。色と形は `--dp-btn-*` で決め、画面ごとに塗り直さない)。

- **主** (クラス無し・`.small`・`.xs`・`.save` など): 操作の層に乗せる。ヘッダー・下のタブと同じ半透明の面 (`--dp-float`) と
  浮かぶものの影 (`--dp-shadow-pop`) のカプセルで、字は本文の色の太字。主の色では塗らない。1 画面に 1 つか 2 つ。
  画面ごとの主の操作 (保存など) は画面の下に置き、中身を送っても見えたままにする
- **浮いたものの中** (メニュー・ダイアログ・下から出す一枚): 主のボタンも浮かせず、太字だけ (`--dp-btn-solid` と `--dp-btn-lift` を消す)
- **控え** (`.secondary`・`.outline`) と **字だけ** (`.ghost`): 平ら。地も枠も影も無い。アイコンと字で押せると分かるようにし、乗せたら薄い地
- **戻せないもの**: 1 回目 (`.outline.danger`) は控えと同じで、乗せたときだけ赤い字。確定 (`.danger`) は主と同じ層で赤い字 (赤では塗らない)
- **入っている切り替え** (`aria-pressed="true"`): ほかの選んでいるものと同じく、主の色の字と短い下線。塗らず、浮かせない
- 形はカプセル (`--dp-radius-full`)。アイコンだけのボタンは円
- 画面ごとに自前の見た目を持つボタン (行・メニューの項目・タブ・チップ・リモコン) は名前のクラスを持たせ、浮かせない

## 入力欄

**入力欄は浮かせず平らにします。** 線も凹みの影も付けず、地より一段濃い面 (`--dp-field`) だけで示します (`app.css` の「入力欄」)。
面は下を透かす薄い色なので、地・件の面・ヘッダーの検索のような操作の層の帯のどれの上でも、そこより一段濃い (暗いほうは明るい) 面になり、下の色に馴染みます。

- ラベルはいつも見せ、欄の場所はラベルと面で分かるようにする (中の字だけの案内に頼らない)
- 字を打っている間は、ほかの焦点と同じ外側の 2px の主の色の線
- 面と地の差は明るいテーマで 1.24:1、暗いテーマで 1.31:1。線を引かないと決めたので、境目の 3:1 (WCAG 1.4.11) には届きません。
  ラベルと焦点の線で補います

## 押した瞬間

押している間の反応と、押した後に残る状態を分けます。

- **押している間**: 主のボタンは少し縮める (97%。平らなボタンは地を一瞬だけわずかに変える)。強い影や大きな動きは使わない
- **押した後**: オン・オフに合わせて字とアイコンの色、線を変える。押している間だけの地や動きは戻す

動きは「押した手応え」を、色と線は「いまの状態」を伝えます。

## 浮かぶもの

メニュー・検索の候補・ダイアログ・画面の下のタブは、操作の層 (上の「地・件の面・操作の層」) です。
**面と影で浮かせます。縁は付けません。** 中身の上に重なるもの (映像の上のメニュー・ヘッダー・下のタブ) は少し透かします。
ページの中で開くメニュー・検索の候補・ダイアログは、後ろが動かないので透かしません。
ぼかし (`backdrop-filter`)・光の反射は、どこにも使いません。

- 面は `--dp-pop` (メニュー・検索の候補)・`--dp-surface` (ダイアログ)
- **映像の上に重ねるものは映像を透かします** (操作バーの影と同じ)。映像の上のメニューはテーマにかかわらず暗い面で、
  地を 86% 残して少し透かす (ぼかさない)。透かしを減らす設定では透かさない
- 影は近い影と遠い影の 2 段 (`--dp-shadow-pop`)
- **ヘッダー (広い画面) と下のタブ (狭い画面) は端から離した角の丸い帯**にして、中身の上に浮かせる。
  面は `--dp-float` (メニューの面を 92% 残す)。暗いほうは面が地より明るいので、影が見えなくても縁が分かる。
  ページごと巻く画面は上端から始めて頭に `--dp-header-space` を空け、巻くとヘッダーの下を流れる。自分で巻き取る画面は上の 2 番
- 透かしを減らす設定 (`prefers-reduced-transparency`) では、ヘッダーと下のタブは透かさず、映像の上の影は濃くします (端へ消えていく形は残す)

## 作り方

- 状態は `color`・`border`・疑似要素 (`::before`・`::after`) の線で作ります。線は押す範囲の内側に引き、高さを変えません
- 影は要るところだけ、控えめな `box-shadow` で
- 動きは短く (`--dp-duration` の 80ms)、`transition` と小さな `transform` だけ。いつも動き続けるものは、いま動いていることを示す印 (録画中の点) だけ
- 選んでいる印を前の場所から滑らせるときは `#lib/motion.svelte.js` の `slide`
- 焦点は `:focus-visible` に外側の 2px の線 (`app.css`)。マウスで押したときは出さない
- 動きを減らす設定 (`prefers-reduced-motion`) では動きを止める (`app.css` の最後)
- 角は入れ子でそろえる (考え方の 5 番)。ボタンや浮いた帯はカプセル (`--dp-radius-full`)、行・入力欄・メニューの項目は `--dp-radius`。
  地・線・字の色は `app.css` の `--dp-*` から選び、画面ごとに新しい色を作らない
