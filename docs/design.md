# 見た目の決まり

画面の見た目の決まりです (手を入れる人向け)。言葉の決まりは [writing.md](writing.md)、画面ごとの説明は [screens.md](screens.md)。
決まりはどこでも同じにし、部品ごとの例外は作りません。

**合言葉: 塗らない。囲みすぎない。浮かせすぎない。でも、ちゃんと伝わる。**

## 1. 考え方

- **ふだんは平らに。** アイコン・字・余白・揃えだけで組み、要らない地の色・枠・影・飾りは付けない
- **強弱は塗りではなく、見た目の順位で。** 選んでいる・オンを強い色で塗るのを標準にしない。色は役目を決めて使う
- **奥行きは層で。** Liquid Glass から層の考え方だけを借りる。ぼかし・屈折・光の反射は使わない (CSS では重い)
- **1 つの意味に印は 1 つ。** 同じことを点と字の濃さの 2 つで言わない。逆に 1 つの見た目に 2 つの意味を持たせない
- **動きは CSS で。** JS では動かさない。動きは「何が起きたか」を伝えるためだけに使う

## 2. 3 つの層

| 層           | 置くもの                                                                                                                                                              | 面                                                                                                                                                                       |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **地**       | 1 行の並び (サイドバー・設定の項目)・映像                                                                                                                             | 平ら。線も影も付けない (`--dp-bg`)                                                                                                                                       |
| **件の面**   | 1 件が 2〜3 行ある一覧の件 (録画・予約・ルール・検索の結果)・番組表のマス                                                                                             | 透かさない面 (`--dp-item`)。明るいほうは白とごく薄い影、暗いほうは地より一段明るい。縁は無し                                                                             |
| **操作の層** | ヘッダー・ヘッダーの下に貼り付く操作の 1 行・下のタブ・画面の下の主の操作・貼り付いた日付の見出し・番組表の「いま」の時刻・番組表の局名と時の列・メニュー・ダイアログ | 面 (`--dp-float` か `--dp-pop`) と 2 段の影 (`--dp-shadow-pop`)。隙間を詰めて並ぶもの (ヘッダーと、その下の操作の 1 行・番組表の局名) は近い影だけ (`--dp-shadow-tight`) |

- **浮いたものの上に、さらに浮いたものを重ねない。** 件の面・メニュー・ダイアログ・下から出す一枚・浮いた操作の 1 行の中のボタンは平らで、主の操作は太字だけ
- **主の操作は色ではなく層で示す。** 主のボタンを操作の層に乗せ、ほかの操作は字とアイコンだけで平ら
- **中身を読んでいる間は引っ込む。** 狭い画面の下のタブ (とその上に浮く 1 行) は下へ送ると隠れ、戻すと出る。引っ込めるのはページごと巻く画面だけ (番組表は表の高さが下のタブの上までで決まっているので引っ込めない)。広い画面のヘッダーは引っ込めない (検索を見せたまま)

## 3. 浮かせ方

**浮かせて透かすのは、動く中身の上に重なるものだけ。** 裏に何も来ないうちは浮かせない。

- **ヘッダー (広い画面) は上端では平ら、巻いて中身が裏に入ると浮く** (面と影が巻いた量に合わせて出る)。面は `--dp-float` (メニューの面を 92% 残す)。
  ぼかさない。字は 4.5:1 以上を保つ。端から離した角丸の面
- **下のタブ (狭い画面) は浮いたまま。** いつも中身がその裏を流れる
- **一覧の画面 (録画・ルール・設定・検索) はページごと巻き**、中身がヘッダーの裏を流れる。頭に `--dp-header-space` を空け、スクロールバーは窓の右端 (ヘッダーの外) に出る
  - サイドバーは地のまま、ヘッダーの下に貼り付けて動かさない (あふれたらサイドバーの中で巻く)
  - 日付の見出しは、ふだんは地の字で、**貼り付いて行がその裏を流れるときだけ**操作の層の小さなカプセルになる (ヘッダーと同じ考え。`scroll-state(stuck: top)`。知らないブラウザはいつもカプセル)
- **ヘッダーの下に貼り付く操作の 1 行は、ヘッダーと同じ角丸の面に乗せ、中身がその裏を流れるときだけ面を出す** (ヘッダー・日付の見出しと同じ考え)。
  番組表の操作の 1 行、ホームの頭の 1 行 (640〜999px)、ルールの頭の 1 行 (768〜999px)、設定の節の行 (640〜767px) で同じ。
  - 形はヘッダーと同じ (`app.css` の `--dp-bar-*`。端からの離れ・角・中の余白)。ヘッダーとの間は `--dp-bar-gap` (0.25rem) 空け、地の色で埋めない
  - 上端では平らで、巻いて中身が裏に入ると面と近い影が出る (`dp-bar-float`)。窓ごと巻く画面は窓の巻いた量、番組表は表の巻いた量で
  - 隙間を詰めて並ぶので、影は近い影 (`--dp-shadow-tight`) だけ。この 1 行がある間はヘッダーも近い影にそろえる (遠い影が下の 1 行に掛かって段々に見えないように)
  - 1 行の中の主のボタンは浮かせず太字だけ (浮いたものの上に浮かせない)
  - スマホでは同じ 1 行を下のタブのすぐ上に浮かせる (いつも浮いた形)
- **観る画面は、箱をヘッダーの下から始める** (`+layout.svelte` の `.shell.fill`)。ヘッダーの裏まで伸ばすと、箱のスクロールバーだけが透けて見える。
  窓が巻けないので、ヘッダーはいつも平ら (アンビエントの色もヘッダーの裏までそのまま届く)
- **番組表 (広い画面) は、表をヘッダーの裏まで伸ばす。** 箱は画面の上端から始め、操作の 1 行はヘッダーの下端に、局名の行はその下に貼り付ける。
  表を巻くとマスがヘッダーと操作の 1 行の裏を流れ、**ヘッダーは窓ではなく表の巻いた量で浮く** (表の箱の時間の軸 `--guide` を `timeline-scope` で外枠まで見せる)。
  操作の 1 行 (上の決まりの形) と局名も、上端では平らで、表を縦に巻くと面が出る
  - 表のスクロールバーは出さない (ヘッダーの裏に透ける)。つかんで動かす・ホイール・キー・指で動く
  - 局名は局ごとの角丸の面 (局の列と一緒に横へ動くので、1 本につながった面にはしない)。操作の 1 行と 0.25rem 空けて並び、近い影
  - 時の列は操作の層。表を巻くとマスがその裏を流れる。影はマスの側 (右) にだけ落とす
  - 768px より狭い画面では今までどおり、表をヘッダーの下から始める
- **映像の上のメニューはテーマにかかわらず暗い面で、映像を透かす** (地を 86% 残す)
- **ステータスバー (スマホ) は、ホーム画面から開いた iPhone で暗いテーマのときだけ透かす** (地を 85% 残した面を敷く)。時刻の字はいつも白になるので、明るいテーマでは地の色で塗ったまま。ブラウザのタブで開いたときは、ブラウザの持ち物なので色 (`theme-color`) を合わせるだけ
- ページの中で開くメニュー・検索の候補・ダイアログは、後ろが動かないので透かさない
- 透かしを減らす設定 (`prefers-reduced-transparency`) では透かさず、映像の上の影は濃くする (端へ消えていく形は残す)

## 4. 印の意味

| 見た目                                | 意味                                                        |
| ------------------------------------- | ----------------------------------------------------------- |
| 文字の幅いっぱいの下線 (横に並ぶもの) | いまいる場所・選んでいるもの (ヘッダーのナビ・種別・日付)   |
| 左の縦線 (縦に並ぶもの)               | いまいる場所・選んでいるもの (サイドバー・局・開いている行) |
| アイコンの下の短い線                  | 機能がオン (プレイヤーの字幕・音を消す・ループなど)         |
| 主の色の太字                          | 線と組んで、選んでいる・オンを補う                          |
| ごく薄い地 / 件の面を一段変える       | 指を乗せた (地の上の行 / 件)                                |
| 外側の 2px の線                       | キーボードで触っているところ (焦点)                         |
| ごく小さな縮み                        | 押した手応え                                                |
| 状態の色 (赤・緑・黄)                 | 録画中・問題・成功・注意。バッジ・通知・進み具合のバー      |
| 淡い地のカプセル (バッジ)             | 状態だけ (録画中・有料・無効・競合)                         |

**下線は長さで意味を分けます。** 幅いっぱいは「選んでいる」、短い線は「オン」。
番組の事実 (ジャンル・映像・音声) はバッジにせず、一覧の補足と同じく控えた字を「・」でつなぎます。

## 5. 色

| 色                                                      | 使うところ                                           |
| ------------------------------------------------------- | ---------------------------------------------------- |
| 主の色 (`--pico-primary`)                               | 線 (下線・左の縦線・オンの短い線)・焦点の線・リンク  |
| 淡い地の上で字にする主の色 (`--dp-primary-text`)        | 選んでいるもの・オンの字とアイコン・土曜             |
| 本文の字                                                | 題名・本文                                           |
| 控えた字 (`--dp-muted`)                                 | 説明・補足 (日時・局・状態)・押せない日 (カレンダー) |
| 録画の赤 (`--dp-rec`)・緑 (`--dp-ok`)・黄 (`--dp-warn`) | 状態だけ。選んでいる印には使わない                   |

- 状態の色を字やアイコンにするときは **`-text` の側** (`--dp-rec-text` など。淡い地の上で 4.5:1 になるよう濃くした段)
- **映像の上はテーマで変えない** (舞台はいつも黒い)。字 `--dp-on-video`・控えた字 `--dp-on-video-muted`・オン `--dp-on-video-on` (空色)・
  戻せないものの 2 回目と「今」 `--dp-on-video-danger` (赤)・メニューの面 `--dp-video-menu`・覆い `--dp-video-veil`
- **読める濃さ**: 字は 4.5:1 以上、線とアイコンは 3:1 以上。両方のテーマで、指を乗せた地・選んだ行の上でも確かめる (e2e `48-link-hover`・`45-buttons`)
- **色だけに頼らない。** 選んでいるものは線と太字、オンは線、状態は印 (点・✕・⚠) と言葉を添える

## 6. 部品

### 選んでいるもの (ナビ・サイドバー・タブ・チップ・カレンダー)

- 通常: 地は塗らない。字は本文 (ナビも薄くしない)
- 選んでいる: 主の色の線 (横は下線、縦は左の縦線) と主の色の太字。**行全体を塗らない**
- 指を乗せた: 地をごく薄く (`--dp-hover-soft`)。選んでいる印とは混ぜない
- チップは枠も地も付けず、入っているものは主の色の太字と下線
- 番組表の日付の土日は、選んでいても土日の字の色のまま (線は主の色)
- カレンダー: 選んでいる日は下線と字。行のある日は本文の字、無く押せない日は控えた字、今日は赤い点 (「いま」と同じ赤)

### 何行かある一覧

- 1 件ずつ件の面 (`app.css` の `.item`) に乗せ、枠と区切りの線は付けない。件の間は `--dp-list-gap` (6px)
- 1 件の中は近づけ、件の間は離す。題名がいちばん強く、説明・補足 (日時・局・状態) の順に控える。サムネイルと字の始まりを揃える
- 右端のボタンはその件の中に置き、位置を件ごとに同じにする。ボタンは平ら
- 指を乗せたら件の面を一段変える (`--dp-item-hover`)。選んでいる・開いている件は左の縦線と太字で、面は塗り替えない
- ボタンの反応は件の反応と分ける (削除に乗せたときだけ赤い字)。削除は 2 回押しで確かめる ([writing.md](writing.md#同じことは同じ文言で))
- 指の端末には乗せる反応が無いので、余白とボタンの置き場を一定にし、押せる範囲を確保する (行は 64px、指の端末では 72px。行の中のボタンは高さ 40px 以上)
- 日付の見出しは貼り付いたときだけ小さなカプセル。「いま」は貼り付かないので地に置き、赤い点と赤い太字の時刻、すぐ後ろに控えた字で次の録画までの一言。
  線は引かない (中身には線を引かない。赤い点と時刻で「いま」と分かる)。左は日付の字にそろえる

### ボタン

色と形は `app.css` の `--dp-btn-*` で決め、画面ごとに塗り直しません。

- **主** (クラス無し・`.small`・`.xs`・`.save` など): 操作の層の面 (`--dp-float`) と影のカプセルで、字は本文の色の太字。主の色では塗らない。
  1 画面に 1 つか 2 つ。保存などは画面の下に置き、中身を送っても見えたままにする
- **浮いたものの中**: 主のボタンも浮かせず太字だけ (`--dp-btn-solid` と `--dp-btn-lift` を消す)
- **控え** (`.secondary`・`.outline`)・**字だけ** (`.ghost`): 平ら。地も枠も影も無く、乗せたら薄い地
- **戻せないもの**: 1 回目 (`.outline.danger`) は控えと同じで乗せたときだけ赤い字。確定 (`.danger`) は主と同じ層で赤い字 (赤では塗らない)
- **入っている切り替え** (`aria-pressed="true"`): 主の色の字と短い下線。塗らず、浮かせない
- 形はカプセル (`--dp-radius-full`)、アイコンだけなら円。自前の見た目を持つもの (行・メニューの項目・タブ・チップ・リモコン) は名前のクラスを持たせ、浮かせない

### 入力欄

- 線も凹みの影も付けず、平らな面 (`--dp-field`) だけ。面は下を透かす薄い色で、地・件の面・ヘッダーのどれの上でも一段濃い (暗いほうは明るい) 面になる
- ラベルはいつも見せる (中の字だけの案内に頼らない)。打っている間は外側の 2px の主の色の線
- 面と地の差は 1.24:1 (明るい)・1.31:1 (暗い) で、境目の 3:1 (WCAG 1.4.11) には届かない。ラベルと焦点の線で補う

### メニュー・ダイアログ・検索の候補

- 面は `--dp-pop` (メニュー・候補)・`--dp-surface` (ダイアログ)。縁は付けず、影だけで浮かせる
- 中のまとまりも線で分けず、余白 (8px) と要るときは控えた字の見出しで分ける
- 横に開く子メニューは使わない (指の端末には乗せる操作が無く、よく使う項目までひと手間増える)
- 項目の角は箱の角から内側の余白を引いた丸み

### 番組表のマス

- マスは面 (地にジャンルの色をごく淡く混ぜる)。枠は引かない
- **ジャンルは時刻の前の小さな点** (ジャンルのメニューの見本も同じ点)。左の太い線は使わない (左の縦線は「選んでいる」の印)
- **予約の状態は時刻の後ろの印と、説明の代わりの太字の言葉**: 予約済みは主の色の ✓、録画中は赤い ●、競合は赤い ⚠ (競合を予約済みと同じ青にしない)。印は説明の行が切れる短いマスでも見える
- 塗るのはいま動いている録画中だけ (録画の赤をごく淡く)
- **放送が過ぎた所は、マスの上から地の色を重ねて沈める** (終わった番組はマス全体、放送中は頭からいまの位置まで。放送中は浅く沈め、終わった番組と見分ける)。表を横切る「いま」の線は引かず、時の列に「いま」の時刻のカプセルだけを置く (分だけ。時は同じ列に出ている)

### 映像の上の操作

- **ボタンは塗らない。** 明るい映像でも読めるよう、並び全体の裏に端から消えていく黒い影を敷く (`ControlBar`)。アイコンと字にも小さな影
- オフは白、**オンは空色のアイコンと下の短い空色の線**。戻せないものの 2 回目と「今」へ張り付いている「ライブ」「最新」は赤い字と赤い短い線
- オンは押した後も残し、いまの設定がいつでも分かるようにする
- 指を乗せた・キーボードで触っているボタンだけ、ごく薄い地を出す
- 読み上げには `aria-pressed`、マウスには `title` で名前を渡す

## 7. 動き

**動きは CSS だけで作り、JS では動かさない。** 時間と曲線は `app.css` の名前から選び、画面ごとに数字を書きません。

| 時間                  | 長さ  | 使うところ                                                                         |
| --------------------- | ----- | ---------------------------------------------------------------------------------- |
| `--dp-duration`       | 120ms | 色・地・影の移り変わり、押して縮む                                                 |
| `--dp-duration-enter` | 240ms | 開く・出てくる (メニュー・ダイアログ・番組の詳細・下から出す一枚・件・画像)        |
| `--dp-duration-move`  | 300ms | 場所が動く (選んでいる印が滑る・浮いた 1 行の出し入れ・スイッチ・縮んだものが戻る) |
| `--dp-duration-exit`  | 150ms | 閉じる・消える (待たせないよう短く)                                                |

曲線は 3 つ: ふつうは `--dp-ease` (終わりをゆっくり)、開く・滑る・戻るは `--dp-ease-spring` (少しだけ行き過ぎて戻るばね)、閉じるは `--dp-ease-exit` (頭をゆっくり)。

- **開くもの** (メニュー・ダイアログ・番組の詳細) は、少し小さく少しずれた透明な姿からばねで出る (`@starting-style`)。閉じるときは短く引っ込む
- **選んでいる印** (タブの下線・ヘッダーのナビの下線・下のタブの印) は、並びの疑似要素 1 本を CSS のアンカーで選んでいる項目に付け、選び直すと前の場所から滑る。
  開いた直後はその場に出る。アンカーを知らないブラウザは項目の中に線を引く (滑らない)
- **ヘッダー**とその下に貼り付く操作の 1 行は、巻いた量に合わせて面と影が出る (`animation-timeline: scroll()`。番組表では表の箱の軸 `--guide`)。
  巻けない短いページでは平らなまま。知らないブラウザと動きを減らす設定の端末は、いつも浮いた形
- **押す**と主のボタンは少し縮み (97%)、離すとばねで戻る。押した後の状態は色と線で示す
- **件**は出てくるときにふわっと出る (透明度だけ。場所は動かさず、読んでいる所をずらさない)。読み込めた画像も同じ (`#lib/motion.svelte.ts` の `fadeIn` は読み込めた合図で印を付けるだけ)
- いつも動き続けるのは、いま動いていることを示す印 (録画中の点・動いているバーの光) だけ
- 動きを減らす設定 (`prefers-reduced-motion`) では、時間を全部 0 にして止める (`app.css` の最後)

## 8. 作り方

- 地・線・字の色は `app.css` の `--dp-*` から選び、画面ごとに新しい色を作らない
- 状態は `color` と疑似要素 (`::before`・`::after`) の線で作る。線は押す範囲の内側に引き、高さを変えない
- 影は要るところだけ、控えめな `box-shadow` で
- 焦点は `:focus-visible` に外側の 2px の線。マウスで押したときは出さない
- **角は入れ子でそろえる** (外の角 = 内の角 + 間の余白)。ボタンと下に浮く 1 行 (スマホ) はカプセル、ヘッダーとその下の操作の 1 行は `--dp-bar-radius` (中の欄の角 + 余白)、行・入力欄は `--dp-radius`、件は `--dp-item-radius`、メニューの項目は箱の角 − 内側の余白
