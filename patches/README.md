# ffmpeg に当てる直し

Dockerfile の `ffmpeg` 段で、組む前に `patch -p1 --fuzz=0` で当てます
(`ffmpeg-*.patch` の名前のものを全部)。**上流に送るつもりのものだけ**を置きます。手元の都合で
ffmpeg の挙動を変えたくなったら、まず denpa 側で済ませられないかを考えます。

**いまは当てているものはありません。** 前に置いていたもの (libaribcaption まわりの直しと、
9.0 / 9.0.1 の長尺で音声が途中で無くなるのを直す `ffmpeg-sched-overflow.patch`) は、
直す先ごと無くなったので消しました。中身と経緯は git の履歴にあります (`git log -- patches/`)。

**9.0.2 で長尺を通しでエンコードした実測はまだありません。** 次に 1 時間超の録画をエンコードしたら、
音声が最後まであるかを一度見ます ([encode.md](../docs/encode.md))。
